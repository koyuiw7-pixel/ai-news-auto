# 検索対象の文字数条件を廃止（2026-10-31）

## オーナーの方針

短くても読者に役立つ記事があるため、文字数だけで検索から外さない。解説や意見を含めるときは、一次情報・事実と、根拠を示した編集部の見方を区別する。確認していない体験を実体験として書かない。

## 変更

- `lib/indexing.ts` と `scripts/indexnow.py` の検索向け判定から、web記事の本文2000文字以上という条件を削除。空本文のweb記事は対象外。明示 `indexable: true/false`、動画・まとめ、特定のPR配信元の従来の扱いは保持。
- 判定は記事のrobots、一般・ニュースサイトマップとIndexNowの候補に使われる。記事を検索対象にできることと、Googleに登録・上位表示されることは別。Googleは文字数の推奨値を設けていない。https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- 元は検索判定が外部配信フィード・メール見本・イベント・週次まとめ・価格表などにも流用されていた。検索の変更が予約・配信内容に波及しないよう `isDistributionEligible` / `is_distribution_eligible` を分け、従来選定を維持。ここに残る文字数条件は**検索用ではなく、既存の配信選定を保つため**。見直す場合は別途配信先と品質を確認する。
- 生成パイプライン `scripts/quality.py` には別途、本文の最低字数と簡単版の字数の品質ゲートが残る。今回変更していない。短い記事を作りやすくするには、出典の照合・情報の充足・事実と見方の分離を備えた代替基準を検証してから、生成・書き直し・品質ゲートをまとめて調整する。検索の条件削除だけで、すべての記事の品質や検索流入が保証されるわけではない。

## 検証

- 変更前のGit版との全774記事比較で、TypeScript・Pythonの既存配信対象の差は0件。検索対象は27件が追加され、除外へ変わる記事は0件。対象数はコンテンツの増減で変化する。
- 追加27件すべてがローカルsitemapに入り、地震・IPAを含む標本の記事HTMLではnoindexなし。既存のPR配信元記事のnoindexは保持。URL・広告・SNS・記事本文は変更していない。
- TypeScript/Pythonの短文・空本文・手動指定・PR配信元・動画・まとめのテスト、ルーティング・広告の既存テスト、IndexNowのdry-run、Webpack版Nextビルドを確認。デプロイ時のワークフローにも両言語の判定テストを追加。IndexNowの通知受理はGoogleの登録を意味しない。

## 今後の観測

デプロイ直後は旧HTMLがエッジに残り得るため、公開記事とサイトマップを実際に再取得し、noindexが外れたことを確認する。Google Search Consoleは対象URLの再クロール・インデックス・表示・クリックを順に確認。追加されたURLのうち、医療・防災・申込期限など読者の判断に影響する記事は一次資料との照合を優先し、誤りがあれば訂正する。検索数値の効果は少数の表示とGoogle側の反映遅延を考慮して評価する。
