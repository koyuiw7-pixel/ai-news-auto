ブックオフのアプリ会員、オンラインストア会員、Web会員だった人の情報が、外部に取得されていたことが分かりました。対象は6,383,279人です。クレジットカード情報や銀行口座情報は含まれていません。自分が対象かどうかは、ブックオフ会員サイトの「WEB照会」で確かめられます。

## 自分は対象か、会員サイトのWEB照会で確かめられます

対象になるのは、ブックオフコーポレーションの会員管理システムに登録されていた会員です。退会した人も含まれます。

| 確かめること | 内容 |
|---|---|
| 対象の会員 | アプリ会員、オンラインストア会員、Web会員 |
| 対象のサービス | BOOKOFF、BOOKOFF SUPER BAZAAR、BOOKOFF PLUS、BOOKOFF公式オンラインストア、あそビバ、BOOKOFF FASHION、BINGO、B・SPORTS、B・STYLE、Rehello by BOOKOFF（店舗） |
| 対象の人数 | 6,383,279人（有効会員6,170,908人、退会会員212,371人） |
| 会員番号ベースの件数 | 6,427,735件 |
| 対象にならない人 | 会員カードのみを使っていて、アプリ登録もウェブ登録もしていない人 |
| 別のシステムで対象外 | hugall、aidect、Rehello by BOOKOFF（ECサイト）、Japan TCG Center、ブクログ、青山ブックセンター、ブックオフおかたづけサービス |

件数と人数に差があるのは、数え方の違いです。6,427,735件から6,383,279人を引くと、44,456件になります（サイソク編集部の計算）。会社は、会員番号ベースの件数に対し、同じメールアドレスで登録された複数の会員データを1人として数えた人数が6,383,279人だと説明しています。

確かめ方は、ブックオフ会員サイトに追加されたWEB照会機能です。登録しているメールアドレスとパスワードでログインすると、自分が対象かどうかが分かります。複数のアカウントを持っている場合は、それぞれのアカウントで確認するよう案内されています。退会済みなどでログインできない場合は、後述の専用フリーダイヤルか問い合わせフォームで確認します。

会員カードからアプリやウェブへ会員情報を引き継いだ人は、対象になる場合があります。カードだけのつもりでも、引き継ぎをした覚えがある人は照会してください。

## 漏れた項目と漏れていない項目

漏えいした可能性のある情報は、アプリ会員、オンラインストア会員、Web会員のいずれかに登録された次の項目です。ただし、すべての会員について、これらすべての情報が漏えいしたわけではないと会社は説明しています。

| 漏えいした可能性のある情報 | 漏えいの対象ではない情報 |
|---|---|
| 氏名 | クレジットカード情報などの決済情報（このシステムでは管理していない） |
| 生年月日 | 銀行口座情報（このシステムでは管理していない） |
| 性別 | 店頭買取で提示した本人確認書類の読み取りによる文字情報と画像 |
| 職業 | 宅配買取で提出した本人確認書類の画像 |
| ニックネーム | 注文時に会員登録住所とは別に指定した配送先情報 |
| メールアドレス | 宅配買取で別に指定した集荷先住所 |
| 電話番号 |  |
| 会員情報として登録された郵便番号・住所 |  |
| パスワードのハッシュ値 |  |
| ポイントカード番号、会員番号 |  |

パスワードのハッシュ値は、パスワードを一定の方式で変換した情報で、そのままでは元のパスワードを読み取ることはできないと会社は説明しています。それでも会社は、対象の会員にパスワードの変更をお願いしています。

2026年11月6日の第3報の時点で、漏えいした会員情報が外部に公開された事実、ポイントが不正に利用された事実、会員情報が書き換えられた事実は確認されていません。

## 会社からの連絡はこの形で届いています

対象の会員への個別メールは、2026年10月15日から登録メールアドレスへ順次送られ、会社が送信可能と確認できたメールアドレスへの送信は10月22日に完了しました。件名は「不正アクセスによる個人情報漏えいに関するお詫びとお知らせ」、送信元は「bookoff@2902.net」です。bookoff.co.jpではないドメインですが、これは会社の公式FAQに載っている正規の送信元です。

あわせて、2026年10月26日から29日にかけて、ブックオフ公式アプリのお知らせ通知でも対象の会員へ個別に案内が出ています。

注意したいのは、個別メールが届いていない場合でも、対象外であることを意味しない点です。メールアドレスの変更や受信設定で届いていない可能性があるため、届いていない人はWEB照会で確かめてください。また、会社から送る案内メールには、パスワード変更画面へ誘導するリンクは載っていません。パスワードやクレジットカード情報、銀行口座情報の入力や返信を求めることもありません。そのようなメールは本物ではないので、リンクを開かずに窓口へ連絡してください。

## 今やること

対象かもしれない人は、次の順で対応してください。

1. ブックオフ会員サイトのWEB照会で、自分が対象か確かめる
2. BOOKOFF公式オンラインストアとブックオフ公式アプリのパスワードを変更する（公式アプリか公式サイトへ自分で直接アクセスして手続きする）
3. 同じか似たパスワードを他のサービスでも使っている場合は、そのサービスでも別のパスワードに変える
4. ブックオフや関係先を装ったメール、SMS、電話に注意し、身に覚えのない連絡のURLや添付ファイルを開かない
5. ポイントの残高や会員情報に身に覚えのない変化があれば、窓口へ連絡する

本件に起因してポイントが不正に利用されたことが確認された場合、そのポイントは会社が全額補塡すると発表しています。身に覚えのないポイントの利用に気づいたら、まず窓口へ連絡してください。

## そもそも何が起きたのか

2026年10月6日、ブックオフコーポレーションの会員管理システムへの第三者の不正アクセスが確認され、10月4日から6日にかけて会員情報が外部から取得されていたことが分かりました。10月9日の第1報では、漏えいの可能性のある会員データは最大約643万件とされました。これは会員番号の件数で、人数ではありません。

10月13日の第2報で、対象が6,383,279人と確定しました。10月16日には、漏えいした可能性のある情報に職業とニックネームが漏れていたとして、第2報の一部が訂正されています。

11月6日の第3報では、外部専門家の協力を得た調査の結果、会員情報を取り扱うシステムの一部機能におけるアクセス制御上の問題を第三者に悪用され、会員情報が取得されていたと原因が特定されました。影響範囲は第2報から変わっていません。個人情報保護委員会へは速報が報告済みで、12月初旬に確報が提出される予定です。警察の捜査にも協力しているとしています。

## サイソクの見方

この件で実務上いちばん大事なのは、メールが届いたかどうかで判断しないことです。会社自身が「届いていない場合でも対象外とは限らない」と明記していて、自分の登録が残っているかはWEB照会でしか確かめられません。

もう1つは、パスワードの扱いです。漏れたのはハッシュ値で、そのまま読める形ではありません。ただ、同じパスワードを他のサービスでも使っているなら、そちら側の危険が残ります。ブックオフ分だけでなく、使い回している先も変えるかどうかが判断の分かれ目です。使い回しがあるなら全部変える、ブックオフ専用のパスワードだったならブックオフ分だけで足ります。
