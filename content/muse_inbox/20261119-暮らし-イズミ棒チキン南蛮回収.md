株式会社イズミの「肉屋の棒チキン南蛮」が自主回収になっています。
中身はチキン南蛮なのに「鶏炭火焼」のラベルが誤って貼られ、小麦・卵・乳成分などの表示が漏れたためです。
販売されたのは、ゆめマート那珂川で2026年11月17日に売られた3個だけです。買った覚えのある人は、食べずに店へ連絡してください。

## 対象かどうかは、店と日付と消費期限で決まります

この回収にはJANコードがありません。届出にJANコードは載っていないため、判定は「買った店・買った日・消費期限」の3点で行います。

| 確かめること | 対象の内容 |
|---|---|
| 商品名 | 肉屋の棒チキン南蛮（一般名称はからあげ、内容量175g、トレー詰め） |
| 誤って貼られたラベル | 鶏炭火焼（内容量100g、トレー詰め）のラベル |
| 消費期限 | 2026年11月20日 |
| 作られた日（製造加工日） | 2026年11月17日 |
| 買った日（販売日） | 2026年11月17日 |
| 買った店（販売先） | ゆめマート那珂川（販売地域は福岡県那珂川市周辺） |
| 販売数量 | 3個 |
| JANコード | 公式には出ていません |

表示が漏れたのは、特定原材料の小麦・卵・乳成分の3つと、特定原材料に準ずるもののごま・大豆・豚肉・りんご・ゼラチンの5つです。3＋5＝8で、合わせて8種の表示が漏れています（サイソク編集部の計算）。

今日は2026年11月19日で、消費期限の2026年11月20日は明日です。期限がまだ残っている分なので、「期限内だから大丈夫」ではなく、ラベルの表示そのものが違う商品として扱ってください。

## 貼られたラベルは、別の商品のものだったという点

この記事だけのなるほどは、間違いの形です。表示の一部が抜けたのではなく、中身の「肉屋の棒チキン南蛮」（175g）に、別商品「鶏炭火焼」（100g）のラベルがそのまま貼られていました。届出には、正しいラベルの画像と、誤った商品の写真、誤ったラベルの画像が並べて載っています。

重さも違います。正しい商品は175g、誤ラベルの商品は100gで、差は75gです。175−100＝75です（サイソク編集部の計算）。手元のトレーのラベルに「鶏炭火焼」「100g」と書かれていて中身がチキン南蛮に見える場合は、この回収の形と一致します。

健康への危険性の程度は、最も重い区分のCLASSⅠとされています。理由の分類例として、アレルゲン（特定原材料に準ずるものを含む）の欠落がCLASSⅠに挙げられています。健康被害の発生状況は、届出では「無」とされています。

## なぜラベルを貼り間違えたのかは、公式には出ていません

届出で分かっているのは、「肉屋の棒チキン南蛮」の商品に「鶏炭火焼」のラベルを誤貼付けした、という事実までです。貼り間違いが起きた工程や原因は、公式には出ていません。

想定される健康被害として届出に書かれているのは、皮膚、消化器、呼吸器などへのアレルギー症状で、重症の場合はアナフィラキシーショックです。小麦・卵・乳成分・ごま・大豆・豚肉・りんご・ゼラチンのいずれかにアレルギーのある人は、対象商品を食べないでください。

## 食べないで、ゆめマート那珂川へ連絡する順番

1. 対象かもしれない商品は食べずに、そのまま保管します。
2. ゆめマート那珂川へ電話（092-953-0300）で連絡します。届出の回収方法は「下記問合せ先にご連絡下さい」となっています。
3. 回収後の対応は、店頭にて返金対応です。返金額そのものは公式には出ていません。
4. 販売店からは、買ったお客様へ電話でお詫びと返金の案内をする、と届出に書かれています。店からの連絡を待つ場合も、手元の商品は食べずに置いてください。

レシートが要るかどうか、店へ持ち込む以外の返金方法があるかどうかは、公式には出ていません。電話で確かめてから動いてください。

## サイソクの見方：売れたのは3個、戻ったのは1個です

届出の数字は小さく、販売数量3個に対して、2026年11月18日18時時点の回収数量は1個です。3−1＝2で、計算上はあと2個が手元に残っている可能性があります（サイソク編集部の計算）。

販売店からは買ったお客様へ電話連絡をすると届出にあるので、残りの分にも連絡が届く見込みですが、連絡先が分からない買い方をしていた場合は届かないことも考えられます。2026年11月17日にゆめマート那珂川で「肉屋の棒チキン南蛮」を買った人は、消費期限（2026年11月20日）が来る前に、冷蔵庫の中を一度だけ確かめてください。
