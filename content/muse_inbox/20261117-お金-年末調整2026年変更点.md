今年の年末調整は、控除の金額が大きく変わります。基礎控除は合計所得金額489万円以下の人で104万円に上がり、給与所得控除の最低保障額は65万円から74万円になります。家族を扶養に入れられる収入の線も、給与だけなら136万円以下に上がりました。

ただし、11月までの給与明細では何も変わっていません。改正の施行が2026年12月1日で、11月までの源泉徴収は今までの税額表のまま計算されているためです。1年分の差は、12月の年末調整でまとめて精算されます。

## 会社員本人は、基礎控除と給与所得控除の2つが変わります

基礎控除は、本人の合計所得金額で金額が決まります。2026年分は次のとおりです。

| 本人の合計所得金額 | 2026年分の基礎控除 | 2025年分 |
| --- | --- | --- |
| 132万円以下 | 104万円 | 95万円 |
| 132万円超336万円以下 | 104万円 | 88万円 |
| 336万円超489万円以下 | 104万円 | 68万円 |
| 489万円超655万円以下 | 67万円 | 63万円 |
| 655万円超2,350万円以下 | 62万円 | 58万円 |
| 2,350万円超2,400万円以下 | 48万円 | 48万円 |
| 2,400万円超2,450万円以下 | 32万円 | 32万円 |
| 2,450万円超2,500万円以下 | 16万円 | 16万円 |
| 2,500万円超 | なし | なし |

合計所得金額は、給与の額面そのものではありません。給与だけの人は、年収から給与所得控除を引いた残りが合計所得金額のもとになります。

給与所得控除は、最低保障額が65万円から74万円に上がりました。給与収入が220万円以下の人の控除が74万円になり、220万円を超える区分の計算式は変わりません。

この2つを合わせると、所得税がかからない目安が見えます。給与収入178万円の人は、178万円から給与所得控除74万円を引くと給与所得は104万円になります（サイソク編集部の計算）。その104万円から基礎控除104万円を引くと、課税される所得は0円になります（サイソク編集部の計算）。社会保険料などのほかの控除がなくても、給与収入178万円までは所得税がかからない計算です。

## 妻や子を扶養に入れている人は、136万円以下が新しい線です

扶養親族と同一生計配偶者の条件は、合計所得金額62万円以下に変わりました。今までは58万円以下でした。家族の収入が給与だけなら、136万円以下が扶養に入れられる線です。今までの123万円以下から広がりました。

136万円という数字は、給与所得控除とつながっています。給与収入136万円から給与所得控除74万円を引くと62万円になります（サイソク編集部の計算）。この62万円が、扶養の条件の上限と一致します。

この改正で新しく扶養に入る家族ができた人は、会社へ扶養控除等（異動）申告書を出す必要があります。国税庁のQ&Aでは、申告書の「異動月日及び事由」の欄に「令和8年12月1日 改正」などと書くよう案内されています。申告書を出さないと、年末調整で扶養控除が反映されません。

注意したいのは、税金の扶養と社会保険の扶養は別の制度だという点です。税金で136万円以下でも、社会保険の扶養に入れるかどうかは別の基準で判断されます。金額をそのまま当てはめないでください。

## 19歳から22歳の子がアルバイトをしている人は、2段階で見ます

19歳以上23歳未満の子は、収入の大きさで親の控除が2段階に分かれます。判定は12月31日時点の年齢です。

子の給与収入が136万円以下なら、今までどおり扶養控除の対象で、親の控除は63万円です。136万円を超えると扶養控除からは外れますが、197万円以下なら特定親族特別控除が受けられます。控除額は最大63万円で、子の収入が増えるほど段階的に減ります。

| 子の給与収入（給与だけの場合） | 子の合計所得金額 | 親が受ける控除 |
| --- | --- | --- |
| 136万円以下 | 62万円以下 | 扶養控除 63万円 |
| 136万円超159万円以下 | 62万円超85万円以下 | 特定親族特別控除 63万円 |
| 159万円超164万円以下 | 85万円超90万円以下 | 特定親族特別控除 61万円 |
| 164万円超169万円以下 | 90万円超95万円以下 | 特定親族特別控除 51万円 |
| 169万円超174万円以下 | 95万円超100万円以下 | 特定親族特別控除 41万円 |
| 174万円超179万円以下 | 100万円超105万円以下 | 特定親族特別控除 31万円 |
| 179万円超184万円以下 | 105万円超110万円以下 | 特定親族特別控除 21万円 |
| 184万円超189万円以下 | 110万円超115万円以下 | 特定親族特別控除 11万円 |
| 189万円超194万円以下 | 115万円超120万円以下 | 特定親族特別控除 6万円 |

| 197万円超 | 123万円超 | なし |

例えば、子の給与収入が159万円なら、159万円から74万円を引いた85万円が合計所得金額になります（サイソク編集部の計算）。85万円以下なので、親の控除は満額の63万円です。

特定親族特別控除を受けるには、会社に出す兼用様式の中の「特定親族特別控除申告書」の欄に書く必要があります。対象は配偶者を除く親族で、学生であることは条件に入っていません。就職した子や専門学校に通う子も、年齢と収入の条件に合えば対象です。

あわせて、年齢23歳未満の扶養親族がいる場合の生命保険料控除の特例も、令和9年分まで延長されました。新しく契約した保険について、一般の生命保険料控除の上限が6万円に広がる特例です。証明書と一緒に、申告書の書き方を確かめてください。

## 11月までに退職した人は、年末調整だけでは足りません

年の途中で退職して再就職していない人は、年末調整を受けられません。1年分の精算は、自分で確定申告をして行います。

退職のときに年末調整を受けた人にも注意があります。最後の給与が11月30日以前に支払われた場合、その年末調整では改正後の控除は適用されません。国税庁のQ&Aは、改正後の控除の適用を受けるためには確定申告等をする必要があるとしています。今年の改正分を取りこぼさないためには、源泉徴収票を持って確定申告に臨むのが確実です。

12月まで同じ会社で働く人は、還付があればその年の最後の給与（通常は12月）で精算されます。還付しきれない分は、その後の月の給与で順次精算されます。

## 自分が当てはまるか、3つの確かめ方

1つ目は、自分の合計所得金額の見積りが489万円以下かどうかです。当てはまれば基礎控除は104万円です。2つ目は、扶養に入れている家族の今年の給与が136万円を超えていないかどうかです。超えていなければ扶養控除が続きます。3つ目は、19歳から22歳の子の給与が136万円を超えていないかどうかです。超えていても197万円以下なら、特定親族特別控除に切り替わります。

## 今やること

基礎控除申告書には、改正後の金額を書いてください。今年は所得の区分の分け方が変わり、489万円以下が1つの区分にまとまっています。去年の申告書を見ながら同じ位置に印を付けると、金額を取り違えるおそれがあります。

新たに扶養に入る家族がいる人は、異動申告書を会社に出してください。特定親族特別控除を受ける人は、兼用様式の該当欄への記入が必要です。申告書は、改正の施行日である12月1日より前に会社へ出しても差し支えないと国税庁のQ&Aにあります。会社の締切が来たら、そのまま出して大丈夫です。

## サイソクの見方

今回の改正は、物価の上昇に合わせて税金がかかり始める線を引き上げるものです。基礎控除と給与所得控除の最低保障額がそろって上がり、給与だけの人の課税最低限は178万円になりました。さらに令和10年分以後は、物価の動きに合わせて2年ごとに見直す仕組みも決まっています。

得の大きさは所得の区分で違います。合計所得金額が336万円超489万円以下の区分では、基礎控除が68万円から104万円に増えます。104万円から68万円を引くと36万円です（サイソク編集部の計算）。控除が36万円増える分、課税される所得は36万円減ります。実際の還付額は、ほかの控除や税率で変わります。

判断の分かれ目は、申告書をどう書くかです。基礎控除の区分を取り違える、新しく扶養に入る家族の異動申告を忘れる、この2つは年末調整で差がつく場面です。逆に、11月までに退職した人は会社任せにできません。自分で確定申告をするかどうかで、改正分の還付を受けられるかが決まります。

## よくある疑問

11月の給与明細で何も変わっていないのはなぜですか。施行が12月1日のため、11月までの源泉徴収事務に変更は生じません。差は12月の年末調整で1年分まとめて精算されます。

還付はいつ戻りますか。年末調整を行った月の給与、通常は12月の給与で精算されます。還付しきれない場合は、その後に支払われる給与から順次差し引いて還付されます。

来年の毎月の天引きは変わりますか。令和9年分の源泉徴収税額表が改正され、令和9年1月1日以後に支払う給与からは新しい税額表で計算されます。今年の年末調整とは別に、来年1月の給与から天引きの額が変わります。

## 公式の窓口

国税庁の「年末調整がよくわかるページ（令和8年分）」が入口です。https://www.nta.go.jp/users/gensen/nencho/index.htm を開き、「給与所得者（従業員）の方へ」へ進むと、申告書ごとの解説と記載例があります。

改正の中身そのものは、国税庁の「令和8年度税制改正による所得税の基礎控除の引上げ等について」にまとまっています。https://www.nta.go.jp/users/gensen/2026kiso/index.htm から、「源泉所得税の改正のあらまし」と「令和8年度税制改正（所得税の基礎控除の引上げ等関係）Q&A」のPDFへ進めます。

金額の根拠を1つずつ確かめたいときは、タックスアンサーが使えます。基礎控除はNo.1199、給与所得控除はNo.1410、特定親族特別控除はNo.1177、扶養控除はNo.1180です。
