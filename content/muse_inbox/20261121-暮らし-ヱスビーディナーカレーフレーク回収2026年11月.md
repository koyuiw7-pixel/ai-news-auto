ヱスビー食品株式会社の業務用「ディナーカレーフレーク1kg」が自主回収になりました。厚生労働省の食品衛生申請等システムに、公開回収事案詳細（RCL202602908）として載っている件です。
理由は、一部商品に製造備品に由来する金属異物が混入した可能性があるためで、回収の理由は「食品衛生法違反のおそれ」とされています。
販売数量は22,635個で、販売地域は全国です。回収に着手したのは2026年11月13日で、健康被害の発生状況は「無」と公表されています。手元にこの商品がある人は、食べずにまずJANコードと賞味期限の印字を確かめてください。

## 金属検出機とX線を通したうえでの回収、というのが今回の理由です

対象を、公式ページで確認できた内容で整理すると、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 商品名 | ディナーカレーフレーク1kg |
| 一般名称 | カレールウ |
| 内容量・形態 | 1kg・袋入り |
| JANコード | 4901002082901 |
| 賞味期限 | 2028年10月17日（印字「2028.10.17」）、2028年10月18日（印字「2028.10.18」） |
| 販売地域 | 全国 |
| 販売先 | 主に業務用ユーザー向け、一部は業務用スーパーでの店頭販売 |
| 販売期間 | 2026年10月29日～2026年11月13日 |
| 販売数量 | 22,635個 |
| 回収着手日 | 2026年11月13日 |
| 健康被害 | 無（2026年11月13日時点で申し出なし） |
| 健康への危険性の程度 | CLASSⅠ |

販売期間は2026年10月29日から11月13日までで、日数にすると16日（サイソク編集部の計算）です。22,635個÷16日＝約1,415個（サイソク編集部の計算）で、1日あたり約1,415個が販売されていた計算になります。

健康への危険性の程度はCLASSⅠとされています。公式ページの分類例では、CLASSⅠに「硬質異物が混入した食品（ガラス片、プラスチック 等）」が挙げられていて、今回の金属異物の混入のおそれは、この分類例に当たります。

一方で、公式ページには「商品は金属検出機およびX線異物検査装置を通しておりますので、万一、混入があった場合でも金属異物は小さく、健康被害が生じる可能性は低いものと想定されます」とも書かれています。検査装置を通した商品について、可能性が否定できない範囲を回収する、という位置づけです。

回収状況は、2026年11月13日時点で回収数量0個・回収割合0％です。回収着手日時点の数字で、始まった直後の段階です。

なぜ起きたか。公式に確認できるのは、一部商品において製造備品に由来する金属異物が混入した可能性があることが判明した、という点までです。どの製造備品が、どのように関わったのかという詳しい経緯や、実際に異物が入っていたかどうかの確認結果は、公式ページには書かれていません。未発表の部分は調査中と明記し、この記事では断定しません。

## 業務用でも、業務用スーパーで買った人は対象になり得ます

対象かどうかは、次の2つで照合してください。

- JANコードが4901002082901であること
- 賞味期限の印字が「2028.10.17」か「2028.10.18」であること

この2つに当てはまる「ディナーカレーフレーク1kg」1kg袋入りが対象です。賞味期限は、商品裏面に印字されています。公式ページには、賞味期限印字箇所の画像として「2028.10.17」と「2028.10.18」の2種類が載っています。

ここが、この記事だけのなるほどです。今回の商品は、公式ページに「主には業務用ユーザー様向けに販売されたものですが、一部、業務用スーパーでの店頭販売もございます」と明記されています。つまり「業務用だから自分は関係ない」とは言い切れません。業務用スーパーで1kg袋を買った一般の人も、同じ2つの数字で対象かどうかが決まります。飲食店や給食などで業務用として仕入れた場合はもちろん、家庭用に買った場合も、印字を確かめる必要があります。

もう1つ、返金の形も先に知っておいてください。今回の回収後の対応は、現金の返金ではありません。公式ページには「後日、商品代金相当のクオカードを発送させていただきます」と書かれています。クオカードを受け取るためにも、商品を捨てずに回収に出す必要があります。

2. 対象なら食べずに、そのまま保管します
3. 回収受付ご登録フォーム（https://customer-support.sbfoods.co.jp/hc/ja/requests/new?ticket_form_id=4998581490718）に必要事項を入力します

## 食べてしまったら、返金はどうなるのか、不安への答えをまとめました

### すでに食べてしまったのですが、健康被害は出ていますか

厚生労働省の詳細ページでは、健康被害の発生状況は「無」と公表されていて、詳細にも「11月13日時点で健康被害のお申し出はございません」と書かれています。あわせて、商品は金属検出機およびX線異物検査装置を通しているため、万一混入があった場合でも金属異物は小さく、健康被害が生じる可能性は低いと想定される、とされています。ただし、体調に異変や不安がある場合は、この公表だけで判断せず、医療機関や同社のお客様相談センター（0120-120-683）に相談してください。

### 返金は現金でもらえますか

現金の返金ではありません。公式ページの「回収後の対応」には、後日、商品代金相当のクオカードを発送すると書かれています。商品を回収に出すことが、クオカードを受け取る前提になります。

### 回収の送料は自分で払うのですか

払いません。公式ページの回収方法には、回収受付ご登録フォームに入力すると同社指定の宅配会社が対象商品を回収に伺い、送料は同社にて負担する、と書かれています。自分で梱包して送る形ではなく、宅配会社が回収に来る形です。

### 賞味期限が2028年と先なのに、なぜ今回収なのですか

賞味期限は2028年10月17日と10月18日ですが、販売は2026年10月29日から11月13日にすでに行われていて、回収の理由は期限ではなく、製造備品に由来する金属異物が混入したおそれがあるためです。期限が残っていても、JANコードと賞味期限の印字が当てはまれば対象です。

### 危険性の程度がCLASSⅠなのに、健康被害の可能性は低いというのは、どういうことですか

公式ページでは、健康への危険性の程度はCLASSⅠとされ、分類例に「硬質異物が混入した食品」が挙げられています。同時に、回収理由の詳細では、金属検出機とX線異物検査装置を通しているため、万一混入があった場合でも金属異物は小さく、健康被害が生じる可能性は低いと想定される、と説明されています。分類は異物の種類に基づく区分で、実際の想定は検査を踏まえた説明として、両方が同じ公式ページに載っています。

## サイソクの見方：業務用スーパーで買った人をどう拾えるかが、この回収の分かれ目です

今回の回収で一番見落とされやすいのは、販売先の広がり方です。販売数量22,635個の多くは業務用ユーザー向けですが、公式に「一部、業務用スーパーでの店頭販売もございます」とある以上、対象は飲食店や事業者だけではありません。1kg袋は家庭でも使い切れる大きさで、業務用スーパーで買った人が「業務用の話だろう」と読み飛ばすと、そのまま残ってしまうおそれがあります。

なぜ今こうなったか。公式に確認できるのは、製造備品に由来する金属異物の混入の可能性が判明し、食品衛生法違反のおそれとして2026年11月13日に回収へ着手したという事実までです。検査装置を通したうえで「可能性は低い」としながら回収に踏み切っている点は、断定できない範囲を残さない対応だと言えます。備品の詳しい経緯は公式には出ていません。

誰がいくら損をするか。対象の袋をそのまま捨ててしまうと、商品代金相当のクオカードを受け取る機会を失います。逆に、フォームから申し込めば送料の自己負担なしで宅配回収され、クオカードが後日届く形です。判断の分かれ目は「捨てる前に、JAN4901002082901と賞味期限の印字2028.10.17・2028.10.18の2つを確かめたか」です。続報で回収割合や健康被害の公表が変わったら、この記事の数字から先に確かめ直します。
