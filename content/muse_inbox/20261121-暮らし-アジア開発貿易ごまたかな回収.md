アジア開発貿易の「伊藤家のごまたかな」が、自主回収になっています。厚生労働省の食品衛生申請等システムに載った回収事案（RCL202602931）で、2026年11月17日に届け出され、11月20日に公開されました。
理由は、お客様から商品の色目と風味異常の申し出があったことによる、食品衛生法違反のおそれです。販売数量は35,400パックと多く、販売地域は全国です。
見分け方はシンプルです。賞味期限の横に印字されたアルファベットの「Y」が、対象品そのものの目印になっています。

## 対象かどうかは、賞味期限の横の「Y」だけでほぼ決まります

対象を、公式ページで確認できた範囲で整理すると、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 商品名 | 伊藤家のごまたかな |
| 事業者 | 株式会社アジア開発貿易 |
| 内容量 | 250g |
| 形態 | 袋包装 |
| JANコード | 4968589001275 |
| 賞味期限 | 2027.05.19Y |
| 対象の目印 | 賞味期限の横にアルファベットの「Y」が印字されている物 |
| 販売地域 | 全国 |
| 販売先 | 小売業者から消費者へ |
| 販売数量 | 35,400パック |

ここが、この記事だけのなるほどです。公式ページの「食品等の特定情報」には、対象の条件として「賞味期限の横にアルファベットの『Y』が印字されている物」とはっきり書かれていて、商品画像の説明にも「賞味期限の末尾がY」とあります。つまり、同じ「伊藤家のごまたかな」でも、期限が「2027.05.19Y」になっていない袋は、この回収では対象として名指しされていません。商品名だけで慌てず、まず期限表示の末尾を見てください。

もう1つ、公式ページには、この商品が輸入食品で輸入国は中国と明記されています。回収の理由は輸入そのものではなく、お客様からの色目と風味異常の申し出です。異常の具体的な原因は、公式ページでは確認できませんでした。分からない原因を推測で書くことはしません。

回収への着手は2026年11月12日で、公開より前から回収が始まっていたことになります。回収状況は「未集計」で、健康被害の発生状況は「無」です。危険性の程度はCLASSⅡとされています。

## 手元の袋は、この順で確かめると迷いません

対象かどうかは、次の順で確かめてください。

1. 商品名と袋：「伊藤家のごまたかな」の250gの袋包装か。JANコードは4968589001275です
2. 賞味期限：期限が「2027.05.19」と印字されているか
3. 末尾の「Y」：期限の横にアルファベットの「Y」が印字されているか。Yがあれば対象、なければこの回収の対象ではありません

## 公式の窓口は、買った店の店舗回収と厚労省の詳細ページです

返金と回収の正式な案内は、事業者のアジア開発貿易です。ただし、公式ページに事業者の電話番号の掲載はありません。載っている回収方法は、次の3点です。

- 周知方法: 事業者のホームページと、販売店におけるPOP周知
- 回収方法: 店舗回収、連絡受付による返送
- 回収後の対応: 返金対応

そのため、最初の一歩は買った店です。対象の袋を持って購入店へ行けば、店舗回収で返金対応を受ける案内になっています。返送を希望する場合は、販売店のPOPか事業者のホームページに載る連絡先を確かめてから送ってください。公式ページに返送先の住所や送料の扱いの記載は確認できませんでした。分からないまま送らず、先に店頭かホームページで確かめるのが確実です。

回収情報そのものを確認する公式ページは、次の2つです。

- 正式名称: 厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602931）
- URL: https://i2fas.mhlw.go.jp/faspub/_link.do?i=IO_S020502&p=RCL202602931
- たどり方: このURLを直接開くと、対象商品・賞味期限の「Y」の条件・回収方法まで載った詳細ページが開きます

- 正式名称: 消費者庁 リコール情報サイト
- URL: https://www.recall.caa.go.jp/index.php
- たどり方: トップページの検索で「伊藤家のごまたかな」や「アジア開発貿易」を入れると、食品のリコール情報を横断して確かめられます

食べて体調に不安がある場合の相談先は、お住まいの地域の保健所です。食品の衛生に関する相談は保健所が窓口で、返金など事業者とのやり取りで困った場合は、消費者庁の消費者ホットライン188（局番なし）が最寄りの消費生活相談窓口を案内します。

## 食べてしまったらどうなるのか、不安への答えをまとめました

### すでに食べてしまいました。どんな症状に気をつければよいですか

公式ページには「お召し上がりになった場合、腹痛、嘔吐などの健康被害が発生する可能性がございます」と書かれています。食べた後に腹痛や嘔吐など体調の異変を感じた場合は、医療機関に相談してください。食品の衛生面の相談は、地域の保健所でも受け付けています。出どころは、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602931）の「健康被害の発生状況」の詳細です。

### 健康被害はもう出ているのですか

出ていません。公式ページの「健康被害の発生状況」は「無」で、「2026.11.17の時点で健康被害は発生しておりません」と書かれています。出どころは、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602931）です。ただし、回収状況は「未集計」で、対象は35,400パックと多いため、まだ家庭に残っている可能性があります。

### 賞味期限が2027年5月と先なのに、なぜ今回収なのですか

賞味期限の長さとは関係なく、お客様から色目と風味異常の申し出があったため、食品衛生法違反のおそれとして回収されています。異常が起きた具体的な原因は、公式ページでは発表されていません。出どころは、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602931）の「回収の理由」と「回収理由の詳細」です。

### 返送する場合の送料はどうなりますか

公式ページでは、回収方法が「連絡受付による返送」で、回収後の対応が「返金対応」とだけ案内されていて、送料の負担までは確認できませんでした。送る前に、買った店か事業者のホームページの案内で、返送先と送料の扱いを確かめてください。

### 「Y」がない袋も返金してもらえますか

この回収で対象とされているのは、賞味期限の横に「Y」が印字された物だけです。「Y」がない袋の返金の扱いは、公式ページでは確認できませんでした。色目や風味に異常を感じる場合は、対象かどうかに関わらず食べずに、買った店へ相談してください。

## サイソクの見方：35,400パックの大きさより、「Y」1文字で判定できる点が救いです

今回の販売数量は35,400パック、販売地域は全国と規模の大きな回収です。健康被害は2026年11月17日時点で報告されておらず、危険性の区分はCLASSⅡです。

なぜ今こうなったか。公式に確認できるのは、お客様からの色目と風味異常の申し出を受けて、食品衛生法違反のおそれとして、公開前の2026年11月12日に回収へ着手したという事実までです。異常の原因は公式に発表されていないので、ここでは推測しません。

誰が当てはまるかは、判定のしやすさで決まります。対象の目印が「賞味期限の横のY」という1文字に絞られているため、買った人は店名や購入日を思い出さなくても、袋を見るだけで自分が対象かどうかを決められます。次に起きそうなことは、回収状況の集計結果の更新です。「未集計」だった数字がどうなるかは、公式ページで確かめられます。

読者への判断は1つです。「伊藤家のごまたかな」の袋が家にある人は、商品名ではなく賞味期限の末尾を見てください。「2027.05.19Y」なら対象、「Y」がなければ対象ではありません。
