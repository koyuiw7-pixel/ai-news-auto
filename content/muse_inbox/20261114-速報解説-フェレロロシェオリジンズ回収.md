日本フェレロの「フェレロ ロシェ オリジンズT-24（24粒入り）」の一部が、日本語の一括表示がない海外向けパッケージのまま売られていたため、自主回収されています。
対象は最大92個で、回収は2026年11月2日に始まりました。アレルギー物質の「乳成分・小麦・大豆」の表示が欠けているため、当てはまる人は食べずに、日本フェレロの窓口へ連絡してください。連絡すると商品代金の返金対応があります。
自分の箱が対象かどうかは、裏面の日本語表示の有無と、ロット番号「L247ZBBNJE」、賞味期限「2027年4月24日」で確かめられます。

## 箱のどこを見れば対象か分かるのか

対象は、製品名だけでは決まりません。公式の特定情報は次のとおりです。

| 項目 | 内容 |
|---|---|
| 製品名 | フェレロ ロシェ オリジンズT-24（24粒入り） |
| 内容量・形態 | 300g、箱詰め |
| JANコード | 6972432060560 |
| 賞味期限 | 2027年4月24日 |
| ロット番号 | L247ZBBNJE |
| 中身 | 3種類のダークチョコレートの詰め合わせ |
| 販売方法 | インターネットサイト（Amazon）を通じた消費者向け販売 |
| 販売数量 | 最大92個 |
| 回収開始日 | 2026年11月2日 |
| 回収の理由 | 日本語の一括表示が貼られていない海外向けパッケージで販売され、アレルギー物質「乳成分・小麦・大豆」の表示が欠けた（食品表示法違反） |

逆に言うと、日本語の一括表示が正しく貼られた通常の国内向け商品は、この回収の対象として案内されていません。まず裏面を見て、日本語の表示シールがあるかどうかを確かめるのが近道です。

## 日本語の表示シールがないまま、どうして売られてしまったのか

日本フェレロの公式発表によると、本来は日本語の一括表示を貼った状態で販売すべきところ、その表示がない海外向けパッケージの状態で販売されていることが判明しました。表示を貼る工程で何が起きたのかという詳しい原因は、公式発表では明らかにされていません。

同社は「今後このような事態を招くことのないよう、表示およびパッケージの確認体制を強化し、再発防止に努める」としています。チョコレートそのものの品質の問題ではなく、表示の欠落が回収の理由です。ただし、その表示にしか書かれていないアレルギー物質の情報が見られないため、厚生労働省のシステムでは危険性の程度が「CLASSⅠ」に区分されています。これはアレルゲンの欠落などが該当する、一番重い区分です。

## 食べかけや開封済みでも返金してもらえるのか、不安への答え

### もう食べてしまったが、体調は大丈夫か

厚生労働省の公開情報では、現時点でお客様による体調不良の申し出はないとされています。一方で、「乳成分・小麦・大豆」のアレルギーがある人が食べると、アレルギー症状を発症するおそれがあるとも明記されています。アレルギーがある人で、食べて体調に異変を感じた場合は、かかりつけ医など医療機関に相談してください。

### Amazonで買った覚えがあるが、メールを見逃していたらどうなるのか

回収の周知として、2026年11月2日にAmazonから購入者へ自主回収情報のメール連絡が実施されています。メールを見逃していても回収が受けられなくなるという案内は、公式情報にはありません。箱の表示とロット番号で対象と分かったら、メールが見つからなくても日本フェレロの窓口へ直接連絡してください。

### 開封してしまった商品や、箱を捨ててしまった場合はどうすればいいのか

開封済みの場合の扱いは、公式発表には書かれていません。箱を捨ててロット番号が確かめられない場合も同じです。あきらめずに、購入履歴が分かるAmazonの注文情報など手元の情報をそろえて、日本フェレロの窓口に状況を伝えて相談してください。

### 返金はどういう形で、いくら戻るのか

厚生労働省の公開情報には、回収後の対応は「商品代金の返金」と書かれています。具体的な返金の進め方や、送料の扱いは公式発表には書かれていないため、連絡した際に窓口で確かめてください。

### 同じフェレロ ロシェのほかの商品も対象なのか

回収の対象として公式に案内されているのは、「フェレロ ロシェ オリジンズT-24（24粒入り）」の特定情報に当てはまるものだけです。ほかの容量や種類のフェレロ ロシェが対象という発表は、今回の公式情報にはありません。

## この回収ならではの確かめ方のコツ

この記事だけのなるほどは、確かめる順番です。ふつうの食品回収ではロット番号から探しますが、この件は「裏面に日本語の一括表示シールが貼られているか」が一番先に分かる目印になっています。海外向けパッケージのまま売られたこと自体が理由なので、表示が全部外国語で、日本語のシールが見当たらなければ、それだけで対象の可能性が高い状態です。そのうえでロット番号「L247ZBBNJE」と賞味期限「2027年4月24日」がそろえば、対象と考えて連絡してください。

もう1つは、対象が最大92個と少ないことです。Amazonで買った人には2026年11月2日に購入者向けのメールが送られているため、受信箱で「フェレロ」や「自主回収」を検索すると、自分の注文が対象かどうかを箱を探す前に確かめられる場合があります。

## サイソクの見方：中身の不良ではなく、表示が見られないことが一番の危険でした

今回の回収は、チョコレートの味や品質に問題があったのではなく、「アレルギーがあるかどうかを買う前に判断するための表示そのものがなかった」ことが理由です。最大92個と数は少なくても、厚生労働省の区分が一番重いCLASSⅠになっているのは、アレルゲンの表示欠落がそれだけ重く扱われるためだと、公式の分類表から読み取れます。

輸入菓子や海外向けパッケージの商品をネットで買うときは、届いた時点で裏面に日本語の一括表示があるかを一度見る習慣が、そのまま自分の身を守る確認になります。表示がない商品を見つけたら、食べる前に販売元やメーカーへ問い合わせるのが安全です。
