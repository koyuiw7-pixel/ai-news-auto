生命保険料控除は、契約した日が平成24年（2012年）1月1日より前か後かで計算が変わります。
新契約（2012年以後の契約）は、一般の生命保険料・介護医療保険料・個人年金保険料の3区分に分かれ、1区分の上限は40,000円、合計は120,000円が上限です。
旧契約（2011年までの契約）は一般と個人年金の2区分で、1区分の上限は50,000円です。同じ一般の保険料を年80,000円払っても、新契約の控除は40,000円、旧契約は45,000円と差が出ます。

## 自分の契約は新か旧か、境目は2012年1月1日です

分かれ目は契約日だけです。平成24年1月1日以後に締結した保険契約等が「新契約」、平成23年12月31日以前に締結したものが「旧契約」で、払っている保険の種類や金額では決まりません（国税庁）。

もう1つ間違えやすいのが、旧契約の医療保険・介護保険です。旧契約には「介護医療保険料」の区分がなく、医療保険や介護保険の保険料も旧生命保険料として計算します。新契約で医療保険に入った場合と、計算の入り口が違うので注意してください。

なお、保険期間が5年未満の生命保険など、控除の対象にならないものもあります。

## 計算式は新旧で4つの段が違い、上限も違います

国税庁の計算式を並べると、違いは「段の区切り」と「上限」にあります。

新契約の計算式（一般・介護医療・個人年金とも同じ）

| 年間の支払保険料等 | 控除額 |
| --- | --- |
| 20,000円以下 | 支払保険料等の全額 |
| 20,000円超 40,000円以下 | 支払保険料等×1/2＋10,000円 |
| 40,000円超 80,000円以下 | 支払保険料等×1/4＋20,000円 |
| 80,000円超 | 一律40,000円 |

旧契約の計算式（一般・個人年金とも同じ）

| 年間の支払保険料等 | 控除額 |
| --- | --- |
| 25,000円以下 | 支払保険料等の全額 |
| 25,000円超 50,000円以下 | 支払保険料等×1/2＋12,500円 |
| 50,000円超 100,000円以下 | 支払保険料等×1/4＋25,000円 |
| 100,000円超 | 一律50,000円 |

ここでいう支払保険料等は、その年に支払った金額から、その年に受けた剰余金や割戻金を差し引いた残りの金額です。

## 自分の場合で比べると、一般だけの人は旧契約のほうが大きくなります

一般の生命保険料を年80,000円払っている場合で比べます。新契約では 80,000円×1/4＋20,000円＝40,000円（サイソク編集部の計算）で、これが上限です。旧契約では 80,000円×1/4＋25,000円＝45,000円（サイソク編集部の計算）になり、同じ保険料でも5,000円の差が出ます。

年100,000円を超えて払っている場合は差が広がります。旧契約は一律50,000円、新契約は一律40,000円で、差は 50,000円−40,000円＝10,000円（サイソク編集部の計算）です。

反対に、新契約には介護医療保険料の区分があります。新契約で一般・介護医療・個人年金の3区分すべてが上限に達すると 40,000円×3区分＝120,000円（サイソク編集部の計算）で、全体の上限120,000円まで使えます。旧契約だけの人は一般と個人年金の2区分なので、両方上限でも 50,000円×2区分＝100,000円（サイソク編集部の計算）が届く範囲です。

新旧の両方に加入している場合は、一般と個人年金のそれぞれで決まりがあります。旧契約分の年間の支払保険料等が60,000円を超える場合は旧契約だけで計算した金額（最高50,000円）を使い、60,000円以下の場合は新契約分と旧契約分の合計額（最高40,000円）を使う、と国税庁は示しています。

## 令和8年分からは、23歳未満の扶養親族がいる人の新契約の上限が広がります

今年の年末調整に関わる変更もあります。令和8年分以降の申告では、23歳未満の扶養親族がいる場合、新契約の一般の生命保険料（新生命保険料）の計算式が別の表になり、上限が60,000円に広がります。

| 年間の新生命保険料 | 控除額 |
| --- | --- |
| 30,000円以下 | 新生命保険料の全額 |
| 30,000円超 60,000円以下 | 新生命保険料×1/2＋15,000円 |
| 60,000円超 120,000円以下 | 新生命保険料×1/4＋30,000円 |
| 120,000円超 | 一律60,000円 |

たとえば新生命保険料を年120,000円払っている場合、通常の表では40,000円が上限ですが、この特例では 120,000円×1/4＋30,000円＝60,000円（サイソク編集部の計算）になり、差は 60,000円−40,000円＝20,000円（サイソク編集部の計算）です。対象は新生命保険料だけで、介護医療保険料と個人年金保険料の式は変わりません。

## 年末調整では、控除証明書を勤務先に出します

生命保険料控除は、勤務先の年末調整で受けるか、確定申告で受けます。国税庁によると、確定申告で受ける場合は、支払金額や控除を受けられることを証明する書類（控除証明書）、または電磁的記録印刷書面を、申告書に添付するか提出の際に提示します。

ただし例外が2つあります。平成23年12月31日以前に締結した旧契約で年間の保険料が9,000円以下のものと、年末調整の際に控除を受けたものは、確定申告での証明書の添付・提示は必要ありません。

年末調整の前にやることは、自分の契約日が2011年までか2012年以後かを確かめることと、保険会社から届く控除証明書の金額が、上の表のどの段に入るかを見ておくことです。

## サイソクの見方

ここからは、上の公式の数字だけを使った、サイソクの見方です。事実とは分けて書きます。

### なぜ新旧で違うのか

平成24年の境目で、仕組みは「2区分で上限50,000円」から「3区分で上限40,000円」に組み替わりました。介護医療の区分を新しく分ける代わりに、1区分あたりの上限は10,000円下がっています。同じ年に契約したかどうかで計算が一生分かれる形で、途中で旧契約の計算に切り替える方法は公式には示されていません。

### 誰がいくら得・損するか

損得は「何の保険を、いくら払っているか」で決まります。一般の保険料だけを多く払っている人は、旧契約の上限50,000円のほうが新契約の40,000円より 10,000円（サイソク編集部の計算）大きく、旧契約側が有利です。逆に、医療保険・介護保険にも入っていて保険料を払っている人は、新契約なら介護医療の区分で最大40,000円が別に数えられるため、区分の数が効きます。ここで比べているのは所得から引ける控除額の差で、実際に減る税金はその人の税率によって変わります。

### 判断の目安は「契約日」と「区分の数」です

旧契約で一般と個人年金の両方を上限近くまで払っているなら、控除の面では旧契約の枠（最大100,000円）が残っている状態です。保険を見直して新しい契約に替えると、契約日が新しくなって新契約の計算に移るため、控除額が減る場合があります。見直しの前に、保障の内容だけでなく控除への影響も並べて確かめてください。

一方、介護医療の保険料を払っているのに旧契約しかないなら、その保険料は旧生命保険料の中で数えられ、区分としては増えません。新契約で介護医療の区分が使えるかどうかが、比べる材料になります。

23歳未満の扶養親族がいるなら、令和8年分は新生命保険料の上限が60,000円に広がる年です。年末調整の申告書を出す前に、扶養親族の年齢と、自分の一般の保険料が年120,000円に近いかどうかを確かめてください。

## よくある疑問に先に答えます

新旧の両方の契約があると、控除はどうなりますか。一般と個人年金のそれぞれで、旧契約分の支払額が60,000円を超えるか以下かで計算のしかたが変わります。超える場合は旧契約だけで計算した金額（最高50,000円）、以下の場合は新旧の合計額（最高40,000円）です。

旧契約の医療保険の保険料は、介護医療の区分で出せますか。出せません。旧契約の医療保険・介護保険の保険料は、旧生命保険料として計算します。

控除証明書がなくても年末調整で出せますか。国税庁の案内では、証明する書類の添付・提示が原則です。例外は、旧契約で年間の保険料が9,000円以下のものと、年末調整で控除を受けたものを確定申告する場合です。

合計の上限120,000円は、新旧どちらの場合でも同じですか。国税庁の式では、各控除額の合計が120,000円を超える場合は120,000円とされています。
