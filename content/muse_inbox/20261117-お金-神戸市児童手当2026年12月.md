神戸市で児童手当を受け取っている人の次回の支給日は、2026年12月10日木曜です。
この日に振り込まれるのは、2026年10月分と11月分の2か月分です。
金額は子1人あたり、3歳未満が月15,000円、3歳以上高校生年代までが月10,000円、第3子以降が月30,000円で、12月はその2か月分が受給者名義の口座に入ります。

## まず早見表で、12月10日に自分の家にいくら入るかを見てください

神戸市の決まりは「偶数月の10日、当日が土曜・日曜・祝日の場合はその直前の平日」です。2026年12月10日は木曜日の平日のため、10日そのままが支給日です。

| 支給月 | 対象月 |
| --- | --- |
| 2月 | 12月分・1月分 |
| 4月 | 2月分・3月分 |
| 6月 | 4月分・5月分 |
| 8月 | 6月分・7月分 |
| 10月 | 8月分・9月分 |
| 12月 | 10月分・11月分 |

| 子の区分 | 月額 | 12月10日に入る2か月分 |
| --- | --- | --- |
| 3歳未満、第1子・第2子 | 15,000円 | 30,000円 |
| 3歳以上高校生年代まで、第1子・第2子 | 10,000円 | 20,000円 |
| 第3子以降（年齢を問わず、上記の区分共通） | 30,000円 | 60,000円 |

3歳未満の第1子が1人なら、15,000円×2か月＝30,000円が12月10日の振込額です（サイソク編集部の計算）。
3歳以上の第1子と第2子が2人なら、10,000円×2人×2か月＝40,000円が12月10日の振込額です（サイソク編集部の計算）。
第3子以降の子が1人いれば、その子については30,000円×2か月＝60,000円が12月10日の振込額です（サイソク編集部の計算）。

対象となる子は、0歳から高校生年代（18歳到達後の最初の3月31日）までの、日本国内に住民登録をしている子です。父母が共に子を養育している場合は、原則として所得の高い方が受給者になると神戸市は案内しています。

## 20歳の上の子がいても10歳の子が第3子になる場合があります

この記事だけのなるほどとして、第3子以降の数え方には、高校を卒業した上の子も含める決まりがあります。神戸市は、養育する子のうち22歳に達した日以降の最初の3月31日を迎えるまでの子（児童養護施設等に入所中の児童を除く）まで含めて、年長者から第1子、第2子と数えるとしています。

神戸市のページに載っている例では、20歳・18歳・10歳の3人を養育している場合、10歳の子は第3子となり月額30,000円です。一方で、23歳・18歳・10歳の場合は23歳の子は数え方に入らず、10歳の子は第2子となり月額10,000円です。上の子が何歳かで、下の子の金額が30,000円にも10,000円にも変わるため、表の「第3子以降」に当てはまるかどうかは、この数え方で確かめてください。

なお、18歳到達後最初の年度末を迎えた人から22歳到達後最初の年度末を迎えるまでの人を多子加算の対象とする場合は、「監護相当・生計費負担の確認書」の提出が必要だと神戸市は案内しています。

もう1つ知っておきたいのが、申請の15日の数え方です。神戸市は、出生や市外転入などで事由が発生した日の翌日から15日以内の申請を求めていますが、その15日目が土日祝祭日や年末年始などの閉庁日に当たる場合は、その翌日を15日目として扱います。例として、市は「3月31日に出生した場合は4月15日までに申請すれば4月分手当から支給される」と示しています。ただし、手続きが遅れると手当を受給できない月が発生するとも案内されているため、閉庁日の救済があるからと先延ばしにせず、早めに出すのが確実です。

## 通知は来ないと神戸市が決めているので、確かめる場所は通帳です

神戸市は「支払いの通知はしませんので、支給日以降に通帳等でご確認ください」と公式に案内しています。12月10日に知らせる紙は届かないため、入金額が上の表の2か月分と合っているかを、通帳や銀行アプリで自分で確かめるのが神戸市での確認方法です。

振込先は、指定した受給者名義の口座です。原則として、児童や配偶者名義の口座へは支給できないと神戸市は案内しています。口座を変えた人は、名義が受給者本人になっているかもあわせて見てください。

## 神戸市で児童手当のことを聞くなら、窓口はここです

問い合わせと郵送・窓口申請の受付は、お住まいの地域の区役所または支所のこども福祉担当です。

- 正式名称：神戸市「児童手当」（神戸市公式ウェブサイトの児童手当のページ）
- 公式ページ：https://www.city.kobe.lg.jp/a32986/kosodate/shien/support/b016/index.html
- たどり方：神戸市公式ウェブサイト（city.kobe.lg.jp）を開いて「児童手当」で検索し、「神戸市：児童手当」のページを開くと、支給要件、支給月額、支給日と対象月の表、手続き方法、送付先とお問い合わせ先が同じページで確かめられます。同ページの「送付先・お問い合わせ先」から、各区役所・支所のこども福祉担当の連絡先一覧へ進めます
- 受付時間：郵送・窓口申請は平日9時00分から17時00分です（神戸市の案内による）
- 電子申請の問い合わせ：神戸市行政事務センターコールセンター 電話078-291-5952

手続きの方法は、電子申請（e-KOBE）と郵送・窓口申請の2種類があります。一部の手続きは郵送・窓口申請でのみ受け付けています。公務員の方は勤務先で手続きをしてください。

12月10日を過ぎても入金が見当たらないときは、まず口座の名義と届出の出し忘れがないかを確かめ、お住まいの区の区役所または支所のこども福祉担当へ相談してください。

## サイソクの見方：神戸市の12月10日は、福岡市と同じ10日でも通知の確かめ方が要る日です

神戸市の支給日は10日で、15日の仙台市や名古屋市より早く、福岡市と同じ日です。ただし早さよりも大事なのは、神戸市が支払いの通知をしないと決めている点です。知らせる紙が来ない以上、10日に口座を見なければ、金額の違いにも入金の有無にも気付けません。

家計の側では、12月10日に入るのは10月分と11月分で、12月分そのものは次の2027年2月の支給に入ることも分けて覚えてください。年内の入金はこの12月10日が区切りになるため、金額が表の2か月分と合っているかを10日当日から数日以内に確かめると、年末の予定がぶれません。

次に読む記事として、福岡市の児童手当は2026年12月10日木曜の記事と、札幌市の児童手当は2026年12月11日金曜の記事もあわせてどうぞ。同じ国の制度でも、支給日と通知の扱いが市ごとに違うことが比べられます。なお、個別記事のスラッグはファイル名から推測して断定できないため、この記事では /articles/ 形式の個別URLは置かず、代わりにサイト内の支給日や締切を確かめる /dates の案内と、金額を確かめる /tools の案内への言及で代替します。
