日本郵便の2027年用（令和9年用）年賀状は、受付開始が2026年12月20日（日）です。
元日（2027年1月1日）に届けたい分は、2026年12月27日（日）までに差し出してください。
年賀はがきは無地とインクジェット紙が1枚85円で、2026年11月2日（月）から販売されています。

今年は日付が例年と違うので、まずここだけ押さえてください。例年の「12月15日から出せる」「12月25日までに出す」で覚えていると、2027年用ではずれてしまいます。

## 2027年用だけ、日付が後ろにずれたのはなぜですか

日本郵便は2026年8月31日の発表で、お客さまの遅出し傾向に合わせたと説明しています。

- 引受開始日を12月20日（日）に繰り下げる（従前は12月15日）
- 元日にお届けするための差出日目安を12月27日（日）に繰り下げる（従前は12月25日）
- 販売終了日を2027年1月15日（金）まで延伸する（従前は1月10日頃）

あわせて日本郵便は、引受開始日を繰り下げても年賀状のお届けが遅れることはないとしています。慌てて早く出す年ではなく、受付が始まってから出す年です。

## 日付を並べると、やることが見えてきます

| 日付 | 出来事 |
| --- | --- |
| 2026年11月2日（月）9時 | 年賀はがきの販売開始、年賀特設サイト「郵便年賀.jp」オープン |
| 2026年12月19日（土）まで | この前に出すと年賀状扱いにならない境目 |
| 2026年12月20日（日） | 年賀状の引受開始 |
| 2026年12月27日（日） | 元日に届けるための差し出しの目安 |
| 2027年1月1日（金） | 元日配達 |
| 2027年1月3日（日） | 三が日のもう1つの配達日 |
| 2027年1月15日（金） | 年賀はがきの販売終了 |

とくに大事なのは12月19日と12月20日の境目です。日本郵便によると、引受開始前（2026年12月19日（土）以前）に差し出された年賀状は、通常郵便の標準送達日数で年内にお届けすることになります。書き終わったからといって12月19日までにポストへ入れると、元日ではなく年内に届いてしまいます。

逆に、12月27日を過ぎたら元日に届かないと決まったわけではなく、日本郵便が「元日にお届けするため、この日までに差し出しをお願いします」と示した目安です。目安を過ぎた分は、元日ではなく1月3日などの配達になる可能性を見ておいてください。

## 1枚いくらですか。種類で80円、85円、90円に分かれます

日本郵便の別紙1「2027（令和9）年用年賀はがきの券種一覧」による売価です。

| 種類 | 1枚の値段 | 補足 |
| --- | --- | --- |
| 無地 | 85円 | 基本の年賀はがき |
| 無地（くぼみ入り） | 85円 | おもて面左下に半円のくぼみがあり、上下・表裏を区別しやすいはがき |
| 無地（インクジェット紙） | 85円 | 家庭のインクジェットプリンター向け |
| 無地（四面連刷） | 340円 | はがき4枚を田型に連ねた大量印刷用。出すときは4枚に切り離す |
| 広告付（5種類） | 80円 | 一部の地域での限定販売。広告が入る分、1枚につき5円安い |
| 寄付金付絵入り（全国版） | 90円 | うち5円が寄付金 |
| 寄付金付絵入り（地方版・23種類） | 90円 | 地域限定のデザイン。うち5円が寄付金 |

枚数で見ると差が分かります。無地を50枚買う場合は85円×50枚＝4,250円です（サイソク編集部の計算）。寄付金付絵入りを50枚買う場合は90円×50枚＝4,500円です（サイソク編集部の計算）。この差250円は、5円×50枚＝250円の寄付金分です（サイソク編集部の計算）。

郵便局のネットショップで買う場合は送料が別にかかります。日本郵便によると、郵便局のネットショップ内「切手・はがきストア」の注文受付は2026年10月26日（月）から2027年1月13日（水）までで、送料はお届け先ごとに全国一律で税込360円（ゆうパケット）または税込720円（ゆうパック）です。お届け先ごとの注文金額が5,000円以上の場合は送料の負担はありません。10枚単位での申し込みです。

広告のために結論を寄せた表ではありません。店頭は送料がかからず、ネットは行く手間が省ける代わりに送料の条件がある、という公式の条件そのままで比べています。

## 受け取る側にも、出した側にも残る小さな仕掛けがあります

この記事だけの「なるほど」は、寄付金付絵入り年賀はがき（全国版）のあて名面です。日本郵便の発表によると、あて名面には全部で3か所、「ひつじ」の文字が隠れています。2027年の干支は未（ひつじ）で、料額印面と通信面には宝袋を載せた松竹梅文様の羊の置物、消印部分にひょうたん、くじ部分に小槌と、縁起物尽くしのデザインになっています。届いたら探してみると、年賀状を開く楽しみが1つ増えます。

もう1つ、2027年用は全ての券種が、森林保全につながるFSC認証を受けた紙で作られています。日本郵便は2022（令和4）年用からこの取り組みを続けており、2027年用でも継続すると発表しています。

当初発行枚数は5億5,593万枚で、発表では5.6億枚、対前年比約74.3％とされています。2026年用の当初発行枚数7.5億枚から減っています。

## 不安になりやすいところを、先に確かめておきます

### 12月15日に出してしまったら、どうなりますか

2027年用の引受開始は12月15日ではなく12月20日です。12月19日以前に出した分は、日本郵便によると通常郵便の標準送達日数で年内に届きます。元日に届けたい分は、12月20日になってから出してください。

### 12月27日にポストへ入れたら、元日に間に合いますか

日本郵便は、2026年12月27日（日）までに差し出していただいた年賀状についても元日にお届けできるよう取り組むとしています。ただしポストには取集時刻があります。その日の取集が終わった後に入れた分は翌日扱いになり得るので、27日当日ではなく、できれば前日までに、遅くとも27日の取集時刻までに出すのが確実です。この取集時刻の注意は一般的な郵便の仕組みからの実務上の注意で、日本郵便の発表は「12月27日までに差し出しをお願いします」としています。

### 年賀はがきを年賀状以外に使いたいときは、どうしますか

懸賞応募など、年賀状としての取り扱い（元日にお届け）を希望しない場合は、年賀状の料額印面下部の「年賀」の文字を二重線などで抹消した上で差し出すよう、日本郵便は案内しています。

### 買いすぎて余ったら、返信に使えますか

販売終了日が2027年1月15日まで延びた理由の1つとして、日本郵便は年賀状の返信のニーズに合わせたと説明しています。元日に届いた年賀状への返信を出す期間も含めて、1月15日まではがきを買えます。

## 日本郵便の年賀特設サイト「郵便年賀.jp」は、ここからたどれます

公式の窓口は、日本郵便の年賀特設サイト「郵便年賀.jp」です。

- 正式名称：年賀特設サイト「郵便年賀.jp」
- URL：https://nenga.yu-bin.jp
- たどり方：ブラウザで上記URLを開くとトップページに「買う」「つくる」「楽しむ」「送る」「知る」の入口があります。年賀はがきを買うなら「買う」から郵便局のネットショップへ、文面を作るなら「つくる」からはがきデザインキット2027や年賀状クイックサーチへ、郵便番号や郵便局を調べるなら「送る」へ進みます。パソコンとスマートフォンで同じURLです
- 日付と値段の元の発表：日本郵便のニュースリリース「2027（令和9）年用年賀はがき等の発行概要」（2026年8月31日）。日本郵便公式サイト（https://www.post.japanpost.jp）のニュースリリースからたどれます
- 電話の問い合わせ：お客様サービス相談センター 0120-23-28-86（フリーダイヤル、全日8時から21時。ガイダンスのあと「*」に続けて「1」を選択）。携帯電話からは0570-046-666（通話料は利用者負担）

## サイソクの見方：遅く出せるようになった分、境目は1つだけ覚えてください

2027年用の変更は、出す側の実態に寄せた変更です。日本郵便自身が「遅出し傾向に合わせた」と書いているとおり、締切を前倒しで守らせるのではなく、受付開始と目安を後ろへずらして、元日配達の仕組みの中に遅めの差し出しを取り込んだ形です。

読者が覚えるべき境目は1つだけです。12月19日までに出すと年内に届き、12月20日から12月27日までに出すと元日を狙えます。はがき自体は11月2日から1月15日まで買えるので、準備は早く、投函は20日以降に、と分けて考えると失敗しません。

年賀状の枚数自体は減っています。当初発行枚数は2026年用の7.5億枚から2027年用は5.6億枚へ、約74.3％になりました（日本郵便の発表）。出す人が減る中で、残った利用者に合わせて日程を組み替える動きと読めます。公式には今後の日程は未発表なので、来年用も同じ日付になるとは書けません。2028年用は、その年の日本郵便の発表で確かめる必要があります。
