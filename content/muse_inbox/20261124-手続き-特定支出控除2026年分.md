先に答えを置きます。2026年分の特定支出控除の対象は、給与所得のある方です。
境目は金額の半分です。その年の特定支出の合計額が、給与所得控除額の2分の1相当額を超えたときだけ、超えた部分を差し引けます。
時期は確定申告です。年末調整では受けられず、明細書と証明書を付けて申告します。

## 対象になる支出は7つ、どれも証明が要ります

国税庁タックスアンサーNo.1415が挙げる特定支出は、次の7つです。

| 特定支出 | 中身 |
|---|---|
| 通勤費 | 一般の通勤者として通常必要であると認められる通勤のための支出 |
| 職務上の旅費 | 勤務する場所を離れて職務を遂行するための直接必要な旅行のために通常必要な支出 |
| 転居費 | 転勤に伴う転居のために通常必要であると認められる支出 |
| 研修費 | 職務に直接必要な技術や知識を得ることを目的として研修を受けるための支出 |
| 資格取得費 | 職務に直接必要な資格を取得するための支出 |
| 帰宅旅費 | 単身赴任などの場合で、勤務地または居所と自宅の間の旅行のために通常必要な支出 |
| 勤務必要経費 | 図書費、衣服費、交際費等。合計額が65万円を超える場合は65万円まで |

ここで止まらないでください。7つの支出は、いずれも、その支出が職務の遂行に直接必要なものであることなどについて、給与の支払者またはキャリアコンサルタントによって証明がされたものに限られます。領収書があるだけでは足りず、証明までそろって初めて入口に立ちます。

### この記事だけのなるほど　職務上の旅費は令和2年分以後に対象に入った支出です

7つのうち、職務上の旅費だけには注記があります。No.1415は、この支出について「令和2年分以後、特定支出の対象となります」としています。出張の旅費を数えるときは、この支出が後から対象に加わったものだという位置付けまで含めて確かめてください。

もう1つ、証明する人の範囲にも線引きがあります。キャリアコンサルタントが証明することで特定支出の対象となるのは、令和5年分以後の研修費または資格取得費で、教育訓練に係る部分に限ります。それ以外の支出の証明は、給与の支払者に求める形です。証明を誰に頼むかで迷ったら、まず支出の種類から分けてください。

逆に、数えてはいけない部分も決まっています。給与の支払者から補てんされる部分があり、その部分に所得税が課税されていない場合、その補てんされる部分は特定支出に含まれません。雇用保険法による教育訓練給付金や、母子（父子）家庭自立支援教育訓練給付金が支給される部分も同じく含まれません。研修費や資格取得費は、給付金が出た分を引いてから合計してください。

## 境目は給与所得控除額の2分の1、控除は超えた分だけです

計算の形は1つです。特定支出の合計額が給与所得控除額の2分の1相当額を超えるとき、その超える部分の金額を、給与所得控除後の所得金額から差し引きます。合計額の全部が控除になる制度ではない点が、この控除で一番間違えやすいところです。

土台になる給与所得控除額は、国税庁タックスアンサーNo.1410の令和8年分・令和9年分の表で確かめられます。この表の金額は、令和8年12月1日に施行され、令和8年分および令和9年分に適用される金額です。

| 給与等の収入金額 | 給与所得控除額（令和8年分・令和9年分） |
|---|---|
| 220万円まで | 74万円 |
| 220万円を超え360万円まで | 収入金額×30％＋8万円 |
| 360万円を超え660万円まで | 収入金額×20％＋44万円 |
| 660万円を超え850万円まで | 収入金額×10％＋110万円 |
| 850万円を超える場合 | 195万円（上限） |

この表から、境目の両端が見えます。収入金額が220万円までの人は給与所得控除額が74万円なので、74万円÷2＝37万円が境目です（サイソク編集部の計算）。収入金額が850万円を超える人は給与所得控除額が上限の195万円なので、195万円÷2＝97万5,000円が境目です（サイソク編集部の計算）。つまり、特定支出の合計がこの境目を超えない年は、申告してもこの控除の金額は出ません。転勤や単身赴任、資格取得が重なった年かどうかで、届くかどうかが変わります。

勤務必要経費にはもう1つの天井があります。図書費、衣服費、交際費等の合計額が65万円を超える場合は、65万円までの支出に限ります。他の6つの支出には、このような金額の上限はNo.1415に書かれていません。本や衣服、交際費だけで境目を狙う場合は、65万円の天井を先に当ててから合計してください。

## 状況ごとに、最初に取る行動が変わります

| 状況 | おすすめ | 理由 | 出どころ |
|---|---|---|---|
| 転勤で転居費や単身赴任の帰宅旅費がかかった | 領収書を集め、給与の支払者に証明を頼む | 転居費と帰宅旅費は特定支出に入り、証明がされたものに限るため | 国税庁No.1415 |
| 研修費や資格取得費に教育訓練給付金が出た | 給付金が支給される部分を除いて合計する | 給付金が支給される部分は特定支出に含まれないため | 国税庁No.1415 |
| 勤務必要経費だけで65万円を超えた | 65万円までとして合計し直す | 勤務必要経費は65万円までの支出に限るため | 国税庁No.1415 |
| 特定支出の合計が給与所得控除額の半分以下 | この控除の申告は見送る | 2分の1相当額を超えた部分だけが控除の対象のため | 国税庁No.1415 |
| 会社から補てんされ、所得税がかかっていない支出がある | その補てん部分を合計から外す | 補てんされ所得税が課税されていない部分は含まれないため | 国税庁No.1415 |

## 公式の窓口は国税庁タックスアンサーNo.1415と所轄税務署です

対象と手続きの確認先は、国税庁 タックスアンサー No.1415「給与所得者の特定支出控除」です。URLは https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1415.htm です。たどり方は、国税庁の公式サイトを開き、「税の情報・手続・用紙」から「税について調べる」、「タックスアンサー（よくある税の質問）」へ進み、番号1415で検索して開く形です。ページの「令和8年4月1日現在法令等」という時点表示まで含めて読んでください。

給与所得控除額の確認先は、国税庁 タックスアンサー No.1410「給与所得控除」です。URLは https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm です。同じくタックスアンサーで番号1410を検索して開くと、令和8年分・令和9年分の表が確認できます。

申告先は所轄税務署です。手続きは、特定支出に関する明細書と、給与の支払者またはキャリアコンサルタントの証明書を申告書に添付するとともに、特定支出に係る支出の事実と支出した金額を証する書類を、申告書に添付するか、申告書を提出する際に提示することとされています。No.1415の関連リンクには、明細書と証明書の様式や、確定申告書等作成コーナーへの案内も置かれています。作成コーナーでは、必要な付表や明細書も入力することで自動的に作成されると案内されています。自分の支出が7つのどれに当たるかで迷う場合は、No.1415のページにある「税についての相談窓口」の案内から相談先を確認してください。

## 申告の前に浮かぶ疑問をほどいておきます

**年末調整で特定支出控除は受けられますか**

受けられません。No.1415は、この控除を受けるためには確定申告を行う必要がある、としています。勤務先の年末調整は通常どおり受けたうえで、この控除は確定申告で申告してください。

**普段着のスーツ代は衣服費に入りますか**

No.1415が衣服費として挙げるのは、制服、事務服、作業服その他の勤務場所において着用することが必要とされる衣服を購入するための支出です。あわせて、職務の遂行に直接必要なものであることなどについて給与の支払者の証明が要ります。証明が得られるかどうかを、勤務先に先に確かめてください。

**会社から交通費の補てんを受けた分も通勤費に数えられますか**

数えられません。給与の支払者から補てんされる部分があり、その補てんされる部分に所得税が課税されていない場合、その部分は特定支出に含まれないとされています。自分で負担した部分だけを合計してください。

**証明書は誰に書いてもらえばよいですか**

原則は給与の支払者です。キャリアコンサルタントが証明できるのは、令和5年分以後の研修費または資格取得費で、教育訓練に係る部分に限ります。支出の種類によって頼む相手が変わるため、明細書を作る前に振り分けておいてください。

## サイソクの見方：届くかどうかは「半分超」と証明の2点でほぼ決まります

誰に・いくら・いつ効くかを先に言います。対象は給与所得のある方で、控除額は特定支出の合計額が給与所得控除額の2分の1相当額を超えた部分だけ、効くのは2026年分の確定申告です。一律の金額はなく、転居費や帰宅旅費、資格取得費が重なった年ほど届きやすくなります。

この控除で先に確かめる価値があるのは、金額より順番です。最初に境目を出すことです。収入金額が220万円までなら境目は37万円、850万円を超えるなら境目は97万5,000円と、収入の帯で大きく変わります。境目を超えそうにない年に領収書をかき集めても控除は出ません。逆に、転勤と単身赴任が重なった年は、帰宅旅費と転居費の両方が対象に入るため、境目を超えるかを一度計算する価値があります。次に証明です。証明がされたものに限るという条件は、申告の直前に動いても間に合わないことがあります。支出が決まった時点で、給与の支払者に証明を頼めるかを確認しておくことが、この控除では金額の計算より先に効きます。

次に何が起きるかは公式には未発表です。令和9年分も同じ仕組みかどうかは、その年のタックスアンサーが何年何月現在法令かまで含めて読み直してから判断してください。今回分については、7つの支出の振り分け、補てん部分と給付金部分の除外、勤務必要経費の65万円の天井、この3点をそろえてから境目と比べる。この順番を守れば、届くかどうかの判断で迷う時間は大きく減ります。
