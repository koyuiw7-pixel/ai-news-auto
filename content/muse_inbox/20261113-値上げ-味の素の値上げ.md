味の素株式会社は、2026年12月1日（火）納品分から、家庭用製品37品種の出荷価格を約5〜15%値上げします。
同じ2026年12月1日納品分から、マヨネーズなどの21品種も約6〜10%の値上げです。
対象は、うま味調味料「味の素®」や塩、甘味料の「パルスイート®」、「ピュアセレクト®マヨネーズ」を買う家庭です。

## 2026年12月1日から値上げになる商品の一覧

1回目の発表（2026年9月1日）で対象になった家庭用製品は37品種です。

| 商品 | 品種数 |
|---|---|
| うま味調味料「味の素®」 | 5品種 |
| 「うま味だし・ハイミー®」 | 3品種 |
| 「アジシオ®」 | 5品種 |
| 「瀬戸のほんじお®」 | 5品種 |
| 「やさしお®」 | 3品種 |
| 「パルスイート®」 | 2品種 |
| 「パルスイート®スリムアップシュガー®」 | 3品種 |
| 「パルスイート®おなかすこやかオリゴ®」 | 1品種 |
| 「クノール®たんぱく質がしっかり摂れるスープ」 | 6品種 |
| 「たんぱく質がしっかり摂れる味噌汁」 | 2品種 |
| 「アクアソリタ®」ゼリー | 2品種 |

2回目の発表（2026年9月9日）はマヨネーズです。家庭用は、「ピュアセレクト®マヨネーズ」250g・400g・600g・1kg、「ピュアセレクト®コクうま® 65％カロリーカット」360g、「ピュアセレクト®サラリア®」210gの6品種で、業務用は15品種です。

この記事だけの「なるほど」は、だしの素の「ほんだし®」が37品種に入っていない点です。入っているのは「うま味だし・ハイミー®」で、「ほんだし®」は今回の発表の対象一覧にありません。名前の似た商品が多いので、対象かどうかは商品名で確かめる必要があります。もう1つ、同じ2026年12月1日開始でも発表は2回に分かれ、値上げ幅も調味料など（約5〜15%）とマヨネーズ（約6〜10%）で違います。

なお、今回の発表は「出荷価格」の改定です。店頭価格は店が決めるため、店頭の値段が同じ率で上がるとは限りません。

## 自分は対象か

対象になるのは、次の商品を買っている家庭です。

- うま味調味料「味の素®」、「うま味だし・ハイミー®」
- 「アジシオ®」、「瀬戸のほんじお®」、「やさしお®」などの塩
- 「パルスイート®」などの甘味料
- 「クノール®たんぱく質がしっかり摂れるスープ」、「アクアソリタ®」ゼリー
- 「ピュアセレクト®マヨネーズ」、「ピュアセレクト®サラリア®」

逆に、「ほんだし®」や「クノール®カップスープ」の通常の商品など、発表の一覧に名前がない商品は、今回の値上げの対象ではありません。

## 自分の買うものでは、いくら上がるか

出荷価格の改定率を、今の店頭価格にそのまま当てはめた場合の目安です。実際の店頭価格は店が決めるため、上がる時期と幅は店によって異なります。

| 例 | 改定率 | 上がり幅の目安 |
|---|---|---|
| 店頭価格300円の調味料 | 5%の場合 | 300円×5%＝15円（サイソク編集部の計算） |
| 店頭価格300円の調味料 | 15%の場合 | 300円×15%＝45円（サイソク編集部の計算） |
| 店頭価格400円のマヨネーズ | 6%の場合 | 400円×6%＝24円（サイソク編集部の計算） |
| 店頭価格400円のマヨネーズ | 10%の場合 | 400円×10%＝40円（サイソク編集部の計算） |

負担の出方を年単位で見ると、マヨネーズを月に1本、400円で買う家庭では、40円×12本＝480円が1年で増える負担の目安です（サイソク編集部の計算）。調味料は1本を長く使う家庭が多いため、1回あたりの差は小さくても、塩・うま味調味料・甘味料・マヨネーズと対象が重なる家庭では、合計で効いてきます。

## 今やること

1. よく買う商品の名前が、公式の発表の対象一覧に入っているかを確かめることです。「ほんだし®」のように、似た名前でも対象外の商品があります。
2. 2026年12月以降に買い替えるとき、店頭価格と内容量の表示を見ることです。今回の発表は価格の改定で、内容量の変更は含まれていません。
3. 業務用マヨネーズも対象のため、外食や惣菜の価格が動く可能性はありますが、公式の発表は出荷価格の改定までで、店の価格への影響は示されていません。

## サイソクの見方

なぜ今こうなったか。味の素株式会社の説明では、家庭用製品は「各製品の主原料をはじめとした原料価格の高騰」に加え、加工費・包材費などが上がり続けているためで、マヨネーズは「中東情勢の影響等を背景に」主原料の油脂の価格が上がっているためです。同社は2026年8月1日納品分から、業務用の調味料や加工食品など191品種の出荷価格を約3〜30%改定した過去があり、今回はその流れが家庭用にも広がった形です。

誰がいくら損するか。対象が調味料とマヨネーズという毎日使う商品のため、1回あたりは15円〜45円の幅でも、対象の商品を何品も使い続ける家庭ほど年間の合計は大きくなります。たとえば、店頭価格300円の調味料を年に4本買う家庭なら、45円×4本＝180円が年間の増える負担の目安です（サイソク編集部の計算）。

読者はどう判断するか。対象の商品を毎日使うなら、2026年12月の買い替えのときに、店頭価格と内容量の両方を確かめてから買うのが目安です。対象外の商品（「ほんだし®」など）だけを使うなら、今回の発表で動く必要はありません。次に何が起きそうかは、公式には未発表です。業務用の次に家庭用が来たという過去の順番はありますが、次の改定の時期や対象は発表されていません。

## よくある質問

### 「ほんだし®」も値上げになりますか

今回の発表の対象一覧に「ほんだし®」はありません。入っているのは「うま味だし・ハイミー®」です。

### 店頭価格も約5〜15%上がりますか

発表は出荷価格（メーカーから問屋や店への価格）の改定です。店頭価格は店が決めるため、上がる時期と幅は店によって異なります。この記事の計算は、出荷価格の率を店頭価格に当てはめた目安です。

### 内容量は減りますか

今回の2つの発表は価格改定のお知らせで、内容量の変更は含まれていません。

### ECで買うプロテイン製品はどうなりますか

「味の素KK プロテインスープ」と「味の素KK プロテインみそ汁」は、2026年11月1日納品分から改定が済んでいます。2026年12月1日から始まるのは、店で売る家庭用37品種とマヨネーズなどです。
