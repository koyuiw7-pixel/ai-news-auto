明城ファーム株式会社の「米粉フィナンシェ」が自主回収されています。理由は消費期限の誤表示です。
表示されている期限は2027年11月30日ですが、正しい期限は2026年11月30日です。差はちょうど1年（サイソク編集部の計算）で、表示を信じると、本当の期限を過ぎてからも長く保管してしまうおそれがあります。
回収着手は2026年11月19日、公開は2026年11月20日です。健康被害は無いとされていますが、手元に対象品がある人は、食べる前にまず期限表示を確かめてください。

## 対象かどうかは、期限表示の2027年11月30日が目印です

対象を、厚生労働省の公開回収事案詳細（RCL202602992）で確認できた範囲で整理すると、次のとおりです。

| --- | --- |
| 商品名 | 米粉フィナンシェ |
| 販売者 | 明城ファーム株式会社 |
| 対象1 | 米粉のフィナンシェ個包装（プレーン、ほうじ茶、紅茶、1個、袋詰め） |
| 対象2 | 米粉のフィナンシェ8個入り箱（1箱、箱詰め） |
| 目印になる表示 | 消費期限「2027年11月30日」 |
| 正しい消費期限 | 2026年11月30日 |
| 回収の理由 | 食品表示法違反（消費期限の誤表示） |
| 販売場所 | 霞が関ビルディングLB階「福井市マルシェ」で消費者向けに小売り |
| 販売日 | 2026年11月18日から11月19日まで |
| 回収着手日 | 2026年11月19日 |
| 健康被害 | 無 |

販売数量は、8個入り箱が3箱と、バラが紅茶1個、ほうじ茶2個、プレーン5個です。バラは合計8個（サイソク編集部の計算）になります。8個入り箱の中身は、プレーン2個、いちご2個、紅茶1個、ほうじ茶1個、抹茶1個、チョコ1個と公表されています。

ここで注意したいのは、本当の期限である2026年11月30日が近いことです。「2027年11月30日」と書いてあっても、2026年11月30日を過ぎたら期限内とは考えないでください。

## 販売は霞が関のマルシェで2日間だけでした

ここが、この記事だけのなるほどです。この商品が売られたのは、霞が関ビルディングLB階の「福井市マルシェ」で、2026年11月18日から11月19日までの2日間だけです。福井の会社の商品ですが、回収の対象になる買い物は東京の霞が関で起きています。福井のお店で買ったものや、ほかの日に買ったものまで対象に広げる記載は、公式ページにはありません。

もう1つ知っておきたいのは、危険性の程度がCLASSⅠとされている点です。公式ページの分類例では、CLASSⅠの例として「消費期限の欠落又は誤表示」が挙げられています。今回のように期限が実際より長く表示されると、期限を過ぎた食品を食べてしまうおそれにつながるため、重い分類になっています。

## 食べても大丈夫か、返金はいつか、不安への答えをまとめました

### 健康被害は出ていますか

公式ページでは、健康被害の発生状況は「無」とされています。回収割合は0パーセント（11月19日時点）と公表されています。出典は、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602992）です。

### なぜCLASSⅠという重い分類なのですか

公式ページの分類例で、CLASSⅠには「消費期限の欠落又は誤表示」が挙げられています。今回は、実際の期限より1年先の日付が表示されていた（サイソク編集部の計算）ため、この分類に当てはまると考えられます。出典は、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602992）です。

### 2026年11月30日までなら、対象品を食べてもよいのですか

公式ページは、対象品を食べずに回収へ出す扱いを示していて、期限内なら食べてよいとは書いていません。表示が「2027年11月30日」のものは、期限が近くても食べずに、料金着払いでの郵送回収に出してください。出典は、厚生労働省 食品衛生申請等システム 公開回収事案詳細（RCL202602992）です。

### 返金はどうやって受けられますか

## サイソクの見方：売られた数は少なくても、期限の1年のずれは見逃せない回収です

今回の販売数量は、8個入り箱3箱とバラ8個（サイソク編集部の計算）と、規模としては小さい回収です。売られた場所も霞が関ビルディングLB階の「福井市マルシェ」に限られ、販売は2026年11月18日から19日の2日間だけでした。

それでも軽く見られないのは、間違いが消費期限そのものだからです。表示は2027年11月30日、正しくは2026年11月30日で、1年のずれ（サイソク編集部の計算）があります。お菓子は「まだ期限が先」と思って棚に置きがちで、表示を信じたまま年を越してしまうと、本当の期限を大きく過ぎてから口にするおそれがあります。

誰がいくら損をするのか。対象品を送れば料金着払いで返金対応とされているため、買い手が送料を負担する形にはなっていません。一方で、返金の具体的な日や方法は公式ページに出ていないので、送る前に問合せ先で確かめることが、買い手側に残された大事な一手です。霞が関のマルシェでこの2日間にフィナンシェを買った人は、まず包みの期限表示だけ確かめてください。それが一番早く、自分が対象かどうかを分ける方法です。
