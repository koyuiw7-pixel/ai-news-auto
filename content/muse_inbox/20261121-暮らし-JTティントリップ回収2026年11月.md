株式会社JTのティントリップ「LKフルーティーグラム」TG120とTG124が自主回収になりました。PMDA（医薬品医療機器総合機構）の医薬品等の回収情報に、化粧品回収の概要（クラスII、回収番号2-13045）として載っている件です。
理由は、成分表示において一部の成分の記載漏れと記載ミスが判明したためです。出荷は2026年11月13日、回収開始は2026年11月18日で、公式の回収概要には「発売日であったために、大半は店頭に並んでおりません」と書かれています。手元にこの2色がある人は、まず色番とロットを確かめてください。

## 書かれていない成分があった、というのが今回の理由です

対象を、公式ページで確認できた内容で整理すると、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 商品名 | LKフルーティーグラムTG120／LKフルーティーグラムTG124 |
| 用途 | ティントリップ |
| 対象ロット | FJ001・FJ002・FJ003（2色とも同じ） |
| 対象数量 | TG120は21,000個、TG124は21,000個（サイソク編集部の計算） |
| 出荷時期 | 2026年11月13日 |
| 回収開始日 | 2026年11月18日 |
| 製造販売業者 | 株式会社JT（東京都渋谷区神宮前一丁目5番8号神宮前タワービルディング21階） |
| 回収の区分 | 化粧品回収の概要（クラスII）、回収番号2-13045 |
| 健康被害 | 報告は今のところない |

対象数量は、公式ページにロットごとの数字が載っています。TG120はFJ001が4,900個、FJ002が8,400個、FJ003が7,700個で、4,900個＋8,400個＋7,700個＝21,000個（サイソク編集部の計算）です。TG124はFJ001が4,339個、FJ002が8,288個、FJ003が8,373個で、4,339個＋8,288個＋8,373個＝21,000個（サイソク編集部の計算）です。2色を合わせると21,000個＋21,000個＝42,000個（サイソク編集部の計算）になります。

記載漏れの内訳は色で違います。TG120は、デカイソステアリン酸ポリグリセリル-10、ホウケイ酸（Ca／Al）、ホウケイ酸（Ca／Na）、シリカ、ホウケイ酸（Ca／チタン）、ステビアエキス、酸化スズ、フィチン酸、ジメチコン、水酸化Al、水添ロジン酸メチル、テトラ（ジ-t-ブチルヒドロキシケイヒ酸）ペンタエリスリチル、酸化チタンの13成分（サイソク編集部の計算）です。TG124は、ホウケイ酸（Ca／Na）、シリカ、ホウケイ酸（Ca／チタン）、酸化スズの4成分（サイソク編集部の計算）です。このほかにTG120では、記載ミスとしてノナイソステアリン酸ポリグリセリル-10とステビオシドの2つの成分名が挙げられています。

健康への影響について、公式ページには「当該商品は化粧品基準を満たす成分のみを配合しており、製品の品質に問題はありません。そのため、重篤な健康被害が発生する可能性はないと考えております。なお、本件における健康被害の報告は今のところありません」と書かれています。中身の品質ではなく、表示の誤りが回収の理由です。

## 色番だけでは決まりません、ロットFJ001からFJ003までが境目です

対象かどうかは、次の2つをセットで照合してください。

- 色番がTG120かTG124であること
- ロットがFJ001・FJ002・FJ003のどれかであること

ここが、この記事だけのなるほどです。ロット番号は、TG120とTG124の2色ともFJ001からFJ003までで共通しています。つまり、ロットだけ見ても色だけ見ても判定できず、色番とロットの組み合わせで初めて対象かどうかが決まります。逆に、TG120やTG124を持っていても、ロットがFJ001からFJ003までに入らなければ、この回収の対象ではありません。

もう1つ知っておきたいのは、店で買えた人が限られる事情です。公式ページには「発売日であったために、大半は店頭に並んでおりません」とあり、回収の方法も「出荷先は全て把握しております」「文書により回収を通知し、対象ロットの自主回収を行います」と、出荷先である店や卸への回収が中心に書かれています。出荷が2026年11月13日、回収開始が2026年11月18日なので、出荷から回収開始までは5日（サイソク編集部の計算）しかありません。

## 返金はどうなるのか、使ってしまったらどうなのか、不安への答えをまとめました

### すでに使ってしまったのですが、体に影響はありますか

PMDAの回収概要では、当該商品は化粧品基準を満たす成分のみを配合しており製品の品質に問題はないため、重篤な健康被害が発生する可能性はないと考えている、とされています。本件における健康被害の報告は今のところありません。ただし、体調に異変や不安がある場合は、この公表だけで判断せず、使用を止めて株式会社JTの品質管理チーム（電話03-6230-9602）や医療機関に相談してください。

### 返金や交換はしてもらえますか

公式の回収概要には、消費者向けの返金・交換の手順や金額は書かれていません。書かれている回収の方法は、出荷先は全て把握していること、文書により回収を通知し対象ロットの自主回収を行うこと、そして発売日であったために大半は店頭に並んでいないことです。発売直後に買ってしまった人は、株式会社JTの品質管理チーム（電話03-6230-9602）へ連絡して、自分の商品の対応を確かめてください。

### 色番がTG120やTG124なら、全部が対象ですか

全部ではありません。対象はロットで区切られていて、FJ001・FJ002・FJ003の3ロットだけです。しかもロット番号は2色で共通なので、色番とロットの両方を確かめてください。ロットがこの3つに入らないTG120・TG124は、この回収の対象ではありません。

### どうして店であまり見かけなかったのですか

公式の回収概要に「発売日であったために、大半は店頭に並んでおりません」と書かれているためです。出荷は2026年11月13日で、回収開始は2026年11月18日でした。出荷先は全て把握されていて、文書による通知で回収が進められています。

### TG120とTG124で、表示の誤りの中身は同じですか

同じではありません。記載漏れはTG120が13成分（サイソク編集部の計算）、TG124が4成分（サイソク編集部の計算）で、TG120には記載ミスの成分名も2つ挙げられています。どちらの色も、誤りの内容はPMDAの回収概要（回収番号2-13045）に成分名まで載っています。

## サイソクの見方：発売の直前に止まった42,000個、消費者の返金案内が公式に無い点が残ります

今回の回収で特徴的なのは、時間の短さです。出荷が2026年11月13日、回収開始が2026年11月18日で、その間は5日（サイソク編集部の計算）です。公式にも「発売日であったために、大半は店頭に並んでおりません」とあり、42,000個（サイソク編集部の計算）の大半は、消費者の手に渡る前に出荷先で止まる形になりました。表示の誤りに発売前の段階で気づけた、という見方もできます。

なぜ今こうなったか。公式に確認できるのは、成分表示で一部の成分の記載漏れと記載ミスが判明したため、対象ロットを自主回収するという事実までです。なぜ記載が漏れたのかという詳しい経緯は、公式の回収概要には書かれていません。

誰がいくら損をするか。ここは正直に書くと、計算ができません。消費者向けの返金・交換の金額や手順が公式の回収概要に出ていないためです。大半は店頭に並ぶ前だったとはいえ、発売直後に買った人がゼロとは公式には言われていません。買ってしまった人の判断の分かれ目は「捨てる前に、色番TG120・TG124とロットFJ001からFJ003を確かめ、JTの品質管理チーム（電話03-6230-9602）に連絡したか」です。続報で消費者向けの対応が公式に出たら、この記事の数字とあわせて確かめ直します。
