## 待てば増える、でも待っている間は1円も入らない

老齢基礎年金と老齢厚生年金は、原則として65歳から受け取れます。65歳で受け取らず、66歳以後75歳までの間で請求する時期を遅らせるのが繰下げ受給です。

遅らせた分だけ年金額が増え、その増額率は一生変わりません。逆に、待機期間中はその年金を受け取れません。増える仕組みと、待つ間に起きることを分けて確認することが出発点です。

まず、自分が対象かどうかを判定します。

- 老齢基礎年金は、受給資格期間が10年以上ある方が65歳から受給できます
- 老齢厚生年金は、老齢基礎年金の受給資格期間があり、厚生年金保険の被保険者期間がある方が65歳から受給できます
- 繰下げの上限は生年月日で分かれます。昭和27年4月2日以後生まれの方は75歳まで、昭和27年4月1日以前生まれの方（または平成29年3月31日以前に受給権が発生している方）は70歳までです
- 特別支給の老齢厚生年金には繰下げ制度がありません。受給開始年齢に達したら速やかに請求するのが公式の案内です
- 老齢基礎年金と老齢厚生年金は、別々に繰り下げることができます。片方だけ遅らせる選択もできます

## 1か月遅らせるごとに、どれだけ増えるのか

増額率の式は、日本年金機構が次のように定めています。

増額率（最大84%）＝ 0.7% × 65歳に達した月から、繰下げを申し出た月の前月までの月数

年齢ごとの率は、公式の早見表では次のとおりです。

| 請求する年齢 | 増額率 |
| --- | --- |
| 66歳 | 8.4% |
| 67歳 | 16.8% |
| 68歳 | 25.2% |
| 69歳 | 33.6% |
| 70歳 | 42.0% |
| 71歳 | 50.4% |
| 72歳 | 58.8% |
| 73歳 | 67.2% |
| 74歳 | 75.6% |
| 75歳 | 84.0% |

たとえば70歳まで待つ場合、待つ期間は60か月です。0.7% × 60か月 ＝ 42%となり（サイソク編集部の計算）、公式の早見表の70歳42.0%と一致します。75歳まで待てば0.7% × 120か月 ＝ 84%で（サイソク編集部の計算）、これが上限です。

増額がかかるのは、年金の本体部分です。老齢基礎年金は振替加算額を除いた額、老齢厚生年金は加給年金額を除いた額に増額率をかけます。加給年金額と振替加算額そのものは、待っても増えません。

## 早くもらう繰上げと並べると、違いが見えてくる

反対の選択である繰上げ受給は、60歳から65歳になるまでの間に受け取り始める仕組みです。早くもらう分だけ減額され、その減額率も一生変わりません。

| 選択 | 1か月あたりの率 | 上限 | 率が決まる時期 |
| --- | --- | --- | --- |
| 繰下げ（66歳から75歳） | 0.7%増 | 最大84%増（75歳） | 申し出た時点で固定、一生変わらない |
| 繰上げ（60歳から65歳、昭和37年4月2日以降生まれの方） | 0.4%減 | 最大24%減（60歳） | 請求した時点で固定、一生変わらない |

60歳で繰り上げると、減る月数は60か月です。0.4% × 60か月 ＝ 24%減となり（サイソク編集部の計算）、公式の早見表の60歳24.0%と一致します。なお、昭和37年4月1日以前生まれの方の繰上げ減額率は1か月あたり0.5%で、最大30%です。

大きな違いがもう1つあります。繰上げは、原則として老齢基礎年金と老齢厚生年金を同時に請求しなければならず、一度請求すると取り消しができません。繰下げは基礎と厚生を別々に選べますが、どちらも「請求して初めて始まる」点は同じです。

## 請求しない限り、年金は始まらない

ここが繰下げでいちばん誤解されやすい点です。年金は、受け取る権利ができたときに自動的に始まるものではありません。日本年金機構は、老齢年金を受け取るためには年金の請求手続きが必要だと明記しています。

流れは次のとおりです。

1. 受給開始年齢に到達する3カ月前に、年金請求書が本人あてに送られてきます。加入記録が記載されているので、もれや誤りがないか確認します
2. 繰下げを考えている場合は、65歳の時点で請求を出さずに待ちます。待つこと自体に、65歳時点での届け出は要りません。受け取り始めたい時期が来たら、その時点で請求します
3. 請求は、お近くの年金事務所か街角の年金相談センターで行います。年金の請求に関する相談は予約ができます（予約方法は後述の窓口案内を見てください）
4. 増額率は、申し出た月の前月までの月数で決まります。1か月判断が遅れるごとに0.7%ずつ変わるため、請求する月そのものが金額を左右します

注意したいのは時効です。請求をせず、年金を受けられるようになったときから5年を過ぎると、5年を過ぎた分の年金は時効により受け取れなくなる場合があります。「待っているつもり」が「請求し忘れ」にならないよう、待つ場合はいつ請求するかを自分で決めておく必要があります。

もう1つの選択肢もあります。繰下げを希望して65歳で請求しなかった人でも、実際の請求時に繰下げの申し出をせず、65歳時点の本来の年金をさかのぼって請求することが可能です。70歳に到達した日以後にさかのぼり請求を選んだ場合は、請求の5年前の時点で繰下げの申し出があったものとみなして増額された年金を一括で受け取る「特例的な繰下げみなし増額制度」があります。対象は昭和27年4月2日以後生まれの方などに限られ、80歳以後に請求する場合などは適用されません。

## 75歳を過ぎてから気づいても、増えるのは75歳まで

この記事だけの具体的な知識として、増額が止まる年齢の扱いを正確に押さえておきます。

65歳に達した時点で受給権がある場合、75歳に達した月を過ぎて請求しても、増額率は増えません。ただし、増額された年金は75歳までさかのぼって決定され、支払われます。つまり、76歳で請求しても率は75歳時点の84%で固定され、待った分が無駄になるわけではありませんが、それ以上増えることもありません。

裏返すと、75歳を過ぎてから慌てて請求しても得られる率は変わらないため、75歳が近づいたら請求の準備を済ませておくのが確実です。昭和27年4月1日以前生まれの方は、この節目が70歳（最大42%）になります。

自分の金額で確かめる方法もあります。日本年金機構の「ねんきんネット」では、年金見込額の試算ができます。「詳細な条件で試算」では、今後の働き方や老齢年金を受け取る年齢を自分で設定して見込額を試算でき、条件の違う結果を比べられます。利用には登録が必要で、マイナポータルとの連携かユーザIDの取得で登録します。ただし75歳以上の方はこの試算を利用できないため、その場合は窓口での確認になります。

電話のつながりやすさにも目安があります。ねんきんダイヤルと予約受付専用電話の公式案内では、夕方（午後4時以降）、週の後半、月の後半（20日以降）がつながりやすいとされています。週の初日は混雑が予想されるため、急がない相談はこの時間帯を狙うのが公式の示すコツです。

## 配偶者の加給年金は、待っている間は出ない

繰下げで見落とされがちなのが、加給年金と振替加算の扱いです。

- 加給年金額と振替加算額は、繰下げによる増額の対象になりません
- 繰下げ待機期間中は、加給年金額も振替加算も受け取ることができません

つまり、配偶者の分の加算がある世帯で老齢厚生年金を繰り下げると、待っている間は本体の年金だけでなく加算分も止まります。そして請求後に受け取る加算分は、待った分だけ増えることもありません。

この影響を避ける方法として公式の仕組み上可能なのが、繰り下げ方を分けることです。老齢基礎年金と老齢厚生年金は別々に繰り下げできるため、加給年金が付く老齢厚生年金は65歳から受け取り、老齢基礎年金だけを繰り下げる組み合わせが選べます。世帯で加算の対象になるかどうかは加入期間や配偶者の年齢で変わるため、自分のケースは試算と窓口確認で確かめてください。

ほかに、待機中に起きると増額が止まる出来事があります。66歳以後の待機期間中に、配偶者の死亡による遺族年金など他の公的年金の受給権を得た場合は、その時点で増額率が固定され、手続きを遅らせても率は増えなくなります。また、繰下げで増えた分（繰下げ加算額）は、遺族厚生年金の額には反映されません。

待機中に本人が亡くなった場合も扱いが決まっています。繰下げ請求は遺族が代わって行うことはできません。遺族から未支給年金の請求が可能な場合は、65歳時点の年金額で決定したうえで過去分が一括して未支給年金として支払われますが、請求した時点から5年以上前の分は時効で受け取れなくなります。

## 働きながら待つ人は、在職で止まる分が増えない

65歳以後も厚生年金保険に加入して働く場合は、在職老齢年金との関係を確認してください。

在職老齢年金は、老齢厚生年金を受けている方が厚生年金保険の被保険者であるときに、年金の基本月額と給与側の総報酬月額相当額の合計に応じて、老齢厚生年金の一部が支給停止になる仕組みです。令和8年度の基準では、合計が月65万円以下なら全額支給、超える場合は超えた分の半分にあたる額が止まります。この65万円は令和8年4月から月51万円から引き上げられた額で、毎年度、賃金の変動に応じて改定されます。なお、老齢基礎年金はこの支給停止の対象ではなく、全額支給となります。

繰下げとの関係で重要なのはここです。65歳以後に厚生年金保険に加入していた期間などに、在職老齢年金制度により支給停止される額は、繰下げの増額の対象になりません。具体的には、止められる部分を除いて増額が計算されます。給与が高いまま働き続ける人ほど、「75歳まで待てば全体が84%増える」という単純な計算にはならないため、自分の支給停止の見込みを含めて試算する必要があります。

## 自分の場合はどうするか、状況別に分けて考える

損得は寿命や働き方で変わるため、ここでは公式の仕組みにもとづく判断の置き方だけを整理します。

| 状況 | おすすめ | 理由 | 出どころ |
| --- | --- | --- | --- |
| 65歳以後も厚生年金に加入して働き続ける人 | まず在職老齢年金で止まる額を確認してから、繰下げ幅を決める | 支給停止される額は繰下げの増額対象にならないため、止まる分が大きいほど増額の効き方は小さくなる。令和8年度は基本月額と総報酬月額相当額の合計が月65万円超で停止が始まる | 日本年金機構「年金の繰下げ受給」「在職老齢年金の計算方法」 |
| 配偶者の加給年金の対象になる人 | 老齢厚生年金は65歳から受け取り、老齢基礎年金だけ繰り下げる分け方を候補にする | 加給年金額は増額対象ではなく、老齢厚生年金を繰り下げると待機中は加給年金自体を受け取れない。基礎と厚生は別々に繰り下げできる | 日本年金機構「年金の繰下げ受給」 |
| 健康に不安があり、待つ間の収入も心配な人 | 繰下げにこだわらず、65歳請求やさかのぼり請求を含めて窓口で試算を比べる | 待機中は年金を受け取れず、待機中に亡くなった場合は65歳時点の年金額で未支給年金として精算される決まりがある。長く待つほど有利とは公式には言えない | 日本年金機構「年金の繰下げ受給」「老齢年金の請求手続きの流れ」 |
| 早く受け取りたいので繰上げを考えている人 | 減額が一生続くことと、取り消しができないことを確認してから決める | 繰上げは1か月あたり0.4%減で60歳では最大24%減となり、その率で生涯受給する。繰下げと違い基礎と厚生は原則同時請求が必要 | 日本年金機構「年金の繰上げ受給」 |
| 75歳まで待つつもりの人 | 75歳に達する前に請求時期を決め、試算は75歳になる前に済ませる | 75歳を過ぎて請求しても増額率は84%から増えず、75歳までさかのぼって決定されるだけ。年金見込額試算は75歳以上の方は利用できない | 日本年金機構「年金の繰下げ受給」「ねんきんネットによる年金見込額試算」 |

このほか、繰下げで年金額が増えると、年金生活者支援給付金や医療保険・介護保険の自己負担と保険料、税金に影響する場合があると公式ページは注意しています。金額の増減だけではなく、手取りや負担の変化も含めて窓口で確認してください。

## 年金事務所とダイヤルは、ここからたどる

繰下げの相談と請求の窓口は、日本年金機構の次の3つです。

### 窓口で相談したいときは、年金事務所と街角の年金相談センター

全国の年金事務所、街角の年金相談センター、街角の年金相談センター（オフィス）で、年金の請求手続きや受給中の年金についての予約相談ができます。

たどり方は、日本年金機構の公式サイト（nenkin.go.jp）を開き、「予約相談について」のページ（ https://www.nenkin.go.jp/section/guidance/yoyaku.html ）から、予約方法と全国の相談・手続き窓口を確認する順番です。老齢年金の請求に関する手続きはインターネット予約の対象で、受付時間は全日午前8時から午後11時30分です。申し込みはマイナポータルから、ねんきんネットから、または登録なしのインターネット予約サイトからでき、登録なしの場合は基礎年金番号とメールアドレスが必要です。

電話で予約する場合は、予約受付専用電話0570-05-4890（ナビダイヤル）です。050で始まる電話などナビダイヤルが使えない場合は03-6631-7521（一般電話）にかけてください。受付時間は月曜日から金曜日の午前8時30分から午後5時15分で、翌日以降の予約を受け付けています。当日の相談を希望する場合は、直接近くの年金事務所へ相談するよう案内されています。予約の際は、基礎年金番号がわかるものを手元に用意してください。

### 電話で聞きたいときは、ねんきんダイヤル0570-05-1165

年金相談に関する一般的な問い合わせは、ねんきんダイヤル0570-05-1165（ナビダイヤル）です。050で始まる電話などでは03-6700-1165（一般電話）を使います。公式ページは https://www.nenkin.go.jp/section/tel/toiawase_ippan.html です。

受付時間は、月曜日が午前8時30分から午後7時、火曜日から金曜日が午前8時30分から午後5時15分、第2土曜日が午前9時30分から午後4時です。第2土曜日以外の土日祝日と12月29日から1月3日は利用できません。相談の際は、基礎年金番号か照会番号がわかるものを用意してください。

自分の年金額そのものは加入記録で決まるため、電話やネットの一般論では確定しません。具体的な金額は、ねんきんネットの年金見込額試算で条件を変えて比べるか、予約相談で自分の記録にもとづく試算をしてもらうのが確実です。
