アルカンの「生鮮ヤマドリダケ」が回収命令の対象になりました。消費者庁リコール情報サイトの商品情報詳細に「回収命令」と載っている件です。
検出されたのは放射性物質（放射性セシウム）で、値は180Bq/kgです。一般食品の基準値は100Bq/kgなので、その基準を超えています。
対応開始日は2026年11月17日です。手元にアルカンの「生鮮ヤマドリダケ」がある人は、食べずにまず対象かどうかを確かめてください。

## まず確かめたいのは、検出値と基準値の差です

対象を、公式ページで確認できた範囲で整理すると、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 商品名 | 生鮮ヤマドリダケ |
| 販売者 | アルカン |
| 検出値 | 放射性セシウム180Bq/kg |
| 一般食品の基準値 | 放射性セシウム100Bq/kg |
| 対応開始日 | 2026年11月17日 |
| 管理番号 | 00000036158（消費者庁リコール情報サイト） |

検出値と基準値の差は、180Bq/kg−100Bq/kg＝80Bq/kg（サイソク編集部の計算）です。倍率で見ると、180Bq/kg÷100Bq/kg＝1.8倍（サイソク編集部の計算）になります。

ロット番号や販売店、販売数量といった「対象の特定情報」は、消費者庁ページにその見出し自体はありましたが、中身はテキストで読み取った範囲では確認できませんでした。そのため、この記事では特定情報を推測で書きません。

## どうして100を超えると回収になるのですか

農林水産省の消費者向け情報では、放射性セシウムの基準値は食品の種類ごとに決まっていて、一般食品は100Bq/kgです。基準値を超過した食品については、回収や廃棄がされると説明されています。

今回の「生鮮ヤマドリダケ」の検出値は180Bq/kgで、一般食品の基準値100Bq/kgを超えています。消費者庁のページでは、この件は自主回収ではなく「回収命令」として載っています。

なぜこの商品から基準値を超える放射性セシウムが検出されたのか、その原因は消費者庁ページの読み取れた範囲では確認できませんでした。産地や経路についても、公式に確認できていないことはこの記事では書きません。

ここが、この記事だけのなるほどです。基準値はすべての食品で同じではなく、飲料水は10Bq/kg、牛乳と乳児用食品は50Bq/kg、一般食品は100Bq/kgと、種類ごとに3段階に分かれています。ニュースで「基準値超え」と聞いたときは、検出値だけでなく、その食品がどの区分の基準と比べられているかを見ると、数字の意味がつかみやすくなります。

一般食品の基準値100Bq/kgと比べると、180Bq/kg−100Bq/kg＝80Bq/kgの超過（サイソク編集部の計算）で、180Bq/kg÷100Bq/kg＝1.8倍（サイソク編集部の計算）です。飲料水の基準値10Bq/kgや牛乳の基準値50Bq/kgは別の食品の区分なので、この商品と比べる基準は一般食品の100Bq/kgです。

## サイソクの見方：数字は1.8倍でも、足りない情報のほうが気になる回収です

今回の検出値180Bq/kgは、一般食品の基準値100Bq/kgの1.8倍（サイソク編集部の計算）です。基準値を超えた食品は回収や廃棄の対象になるという仕組み自体は、農林水産省の説明どおりに動いています。

一方で、この件は買った人にとって確かめにくい回収でもあります。ロットや販売店といった特定情報と、事業者の連絡先が、ページをテキストで読んだ範囲では拾えなかったためです。対象かどうかを自分で絞り込めない場合は、「商品名と販売者」という2つの手がかりで買った店に聞くのが一番早い判断です。

なぜ今こうなったか。公式に確認できるのは、基準値を超える放射性セシウムが検出され、回収命令として公表されたという事実までです。原因が公式に出ていない以上、産地や流通経路の推測はしません。続報で特定情報が読める形で出たら、この記事の未確認点から先に埋め直します。
