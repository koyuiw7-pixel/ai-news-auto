前回から変わったこと：各手続きに「自分が対象か」「次に何をするか」と、発表元と確認日を足しました。


| 手続き | 自分が対象か | 次に何をするか |
| --- | --- | --- |
| 還付申告 | 源泉徴収や予定納税で所得税を納め過ぎた人。年の途中で退職し年末調整を受けなかった人など。源泉徴収票の所得税額が「0」の人は、申告しても所得税は戻らない | 源泉徴収票で納めた所得税を確かめ、対象年の翌年1月1日から5年以内に税務署へ提出する |
| 年末調整の精算 | 給与の支払を受けている人 | 勤務先が税額の過不足を精算する。納め過ぎた税金は、通常12月分として納付する源泉徴収税額から差し引いて返されるので、給与明細で確認する |
| 申告書の郵送 | 申告書を郵送で提出する人 | 第一種郵便物か信書便で送る。通信日付印に表示された日が提出日とみなされる |
| ふるさと納税のワンストップ特例 | 確定申告が不要な給与所得者などで、寄附先が5団体以内の人 | 寄附先の自治体へ申請する。埼玉県の案内では、申請書は寄附した年の翌年1月10日必着 |
| 国の行政機関の休み | 窓口や電話相談を使う人 | 12月29日から翌年1月3日までは国の行政機関の休日で、執務は原則として行われない。その前に相談や提出を済ませる |
| ねんきんダイヤル | 年金の一般的な相談をしたい人 | 0570-05-1165へ電話する。12月29日から1月3日までは利用できない。基礎年金番号または照会番号が分かるものを用意する |
| 国税相談専用ダイヤル | 国税について電話で相談したい人 | 0570-00-5901へ電話する。申告書の提出状況や還付金の処理状況は、この窓口では回答できない |
| 消費者ホットライン | 消費者トラブルの相談をしたい人 | 局番なしの188へ電話する。自宅の郵便番号を入力すると、最寄りの消費生活相談窓口につながる |


| 手続き | 発表元 | 確認日 |
| --- | --- | --- |
| 還付申告 | 国税庁 No.2030「還付申告」 | 2026年11月25日 |
| 申告書の郵送 | 国税庁の送付案内 | 2026年11月25日 |
| ふるさと納税のワンストップ特例 | 総務省の制度説明、埼玉県の案内 | 2026年11月25日 |
| 国の行政機関の休み | 行政機関の休日に関する法律 | 2026年11月25日 |
| ねんきんダイヤル | 日本年金機構の案内 | 2026年11月25日 |
| 消費者ホットライン | 政府広報オンラインの案内 | 2026年11月25日 |
