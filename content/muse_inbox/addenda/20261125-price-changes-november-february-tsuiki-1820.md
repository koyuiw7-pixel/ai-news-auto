## 11月から2月の値上げ・値下げごとに、自分が対象かと次にすること

### 自分が対象かと次に何をするか

| 項目 | 自分が対象か | 次に何をするか |
| --- | --- | --- |
| りくろーおじさんの店（2026年11月24日） | 全店で一部商品の価格が改定された。利用する人が対象 | 対象商品の名前や商品別の新価格は同店のお知らせに示されていないため、購入前に店頭の価格を確認する |
| くら寿司（2026年11月27日） | くら寿司を利用する人。22商品が10〜30円値上げ、34商品が10〜70円値下げ | 11月27日以降は改定後の価格で注文する |
| ahamo（2026年12月1日） | 「ahamo」の契約者全員。大盛りオプションを契約していない人で2026年11月1日時点で契約していた人には、40GBの上限が自動で設定される | 上限が不要な人は、ahamoアプリ・My docomoで解除できる |
| SoftBank 光・Air（2026年12月利用分から） | 対象プランの契約者。「SoftBank 光・10ギガ」は対象外。自動更新プランは契約期間満了月の翌月利用分から改定 | 続ける人は適用月と「PayPayカード割（B）」の条件を確認する。料金改定を理由に解約する人は、2026年11月30日までの手続きで解除料が免除される |
| 最低賃金（2026年12月1日・岩手県と熊本県） | 岩手県・熊本県で働く人 | 給与明細の時給を、改定後の金額（岩手県1,090円、熊本県1,092円）と照らす |
| 最低賃金（2026年12月2日・沖縄県） | 沖縄県で働く人 | 給与明細の時給を、改定後の金額（1,086円）と照らす |
| 明治の食品（2027年1月1日出荷分） | アイスクリーム、チーズ、バター・油脂類の対象品を買う人。これは出荷価格の改定で、店頭の販売価格と同じ数字ではない | 店頭の販売価格を確認する |
| 明治のアイスクリーム（2027年1月下旬以降） | 「明治ブルガリア フローズンヨーグルトデザート」を買う人。内容量が85mlから80mlに変わる | 購入時に内容量と価格を確認する |
| 明治のレトルトカレー（2027年2月1日出荷分） | 対象6品を買う人。出荷価格が約12％引き上げられる | 店頭の販売価格を確認する |
