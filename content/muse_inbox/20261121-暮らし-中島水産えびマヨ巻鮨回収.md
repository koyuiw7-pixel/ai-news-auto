中島水産株式会社の「えびマヨネーズ巻鮨」が自主回収の対象になりました。厚生労働省の食品衛生申請等システムに、事案番号RCL202602984として公開されている件です。
理由は、アレルゲン表示（小麦）の欠落で、食品表示法違反に当たるとされています。健康への危険性の程度はCLASSⅠとされています。
売られたのは近鉄百貨店橿原店の中島水産売場だけで、期間は2026年11月14日から17日までです。対象の日にこの売場で買った人は、まず買った日を確かめてください。

## 買った日が11月14日から17日なら、対象かどうかが分かります

対象を、公式ページの記載どおりに整理すると、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 商品名 | えびマヨネーズ巻鮨 |
| 内容量と形態 | 8切、パック販売 |
| 販売店 | 近鉄百貨店橿原店の中島水産売場（奈良県内） |
| 販売日 | 2026年11月14日から11月17日まで |
| 販売数量 | 計32P |
| 消費期限 | それぞれ販売当日中 |
| 回収の理由 | アレルゲン表示（小麦）の欠落による食品表示法違反 |
| 回収着手日 | 2026年11月19日 |

日別の製造販売数は、11月14日が10P、11月15日が10P、11月16日が10P、11月17日が2Pです。10P＋10P＋10P＋2P＝32Pで、公式ページの「計32P」と一致します（サイソク編集部の計算）。

ここが、この記事だけのなるほどです。回収の案内では販売数量が合計だけ書かれることも多いのですが、この件は公式ページに日別の製造販売数まで細かく出ています。レシートや買い物の記録に日付が残っていれば、自分の買った日と日別の数を照らし合わせて、対象の日に買ったかどうかを確かめる手がかりになります。

消費期限はそれぞれ販売当日中です。そのため、通常の保存では対象商品が手元に残っている可能性は低いと考えられます。ただし、公式ページでは保存方法によって対象を分ける記載はありません。もし何らかの形で残っていた場合は、食べずに売場へ問い合わせてください。

## なぜ小麦の表示が無いだけで回収になるのですか

公式ページでは、回収理由の詳細は「アレルゲン表示（小麦）の欠落」とされています。健康への危険性の程度はCLASSⅠで、同じページの分類例でも、アレルゲンの欠落はCLASSⅠに含まれる表示事項として示されています。

健康被害の発生状況は「無」とされ、現在のところ健康被害発生の報告はないと記載されています。一方で、小麦にアレルギーをお持ちの方が食べた場合、食物アレルギー症状を起こす可能性があるとも事業者側の詳細として書かれています。表示が無いと、買う側は小麦が入っているかどうかをパッケージで判断できません。そこが、この回収の中心です。

なぜ表示が欠けたのか、その原因は公式ページには書かれていません。原因が公式に出ていない以上、この記事では推測しません。

## 食べたかもしれない、返金はどうなるのか、不安への答えです

### 対象の商品を食べてしまったら、危ないのですか

公式ページでは、健康被害の発生状況は「無」で、現在のところ健康被害発生の報告はないとされています。ただし、小麦にアレルギーをお持ちの方が食べた場合、食物アレルギー症状を起こす可能性があるとも書かれています。小麦アレルギーがある人で体調に異変がある場合は、医療機関へ相談してください。出どころは厚生労働省の公開回収事案詳細（RCL202602984）です。

### 自分が対象かどうかは、どこで確かめればいいですか

買った店と買った日で確かめます。対象は近鉄百貨店橿原店の中島水産売場で、2026年11月14日から17日に売られた「えびマヨネーズ巻鮨」8切パックです。公式ページには日別の製造販売数（14日10P、15日10P、16日10P、17日2P）も載っているので、レシートの日付と照らし合わせられます。出どころは厚生労働省の公開回収事案詳細（RCL202602984）です。

### 返金はしてもらえますか

公式ページの回収方法には「返金対応」と書かれています。問い合わせ先は（株）近鉄百貨店 橿原店 地階 中島水産売場で、電話は0744-25-3732です。返金に商品やレシートが必要かは公式ページに書かれていないため、電話で先に確かめてください。出どころは厚生労働省の公開回収事案詳細（RCL202602984）です。

### 消費期限が当日中なら、もう気にしなくていいのですか

消費期限はそれぞれ販売当日中のため、通常はすでに期限を過ぎていて、手元に残っている可能性は低いです。ただし、公式ページは保存状態で対象を分けていません。残っているものを見つけた場合は食べずに、売場へ連絡してください。出どころは厚生労働省の公開回収事案詳細（RCL202602984）です。

### ほかの近鉄百貨店の店舗で買ったものも対象ですか

公式ページの販売先は近鉄百貨店橿原店とだけ書かれていて、販売地域は奈良県内とされています。ほかの店舗で買った商品は、この件の対象としては書かれていません。不安な場合は、買った店舗ではなく、この件の問い合わせ先（電話0744-25-3732）で確かめるのが確実です。出どころは厚生労働省の公開回収事案詳細（RCL202602984）です。

## サイソクの見方：32パックと小さいのに、小麦アレルギーの人には見逃せない回収です

販売数量は計32Pと、回収としては小さい規模です。日別の内訳も14日から16日が各10P、17日が2Pと公式に出ていて、対象は店も日も狭く特定できます。買った人の大半は、店と日付の2つで自分が対象かどうかを判断できます。

それでも軽く見られないのは、理由がアレルゲン表示（小麦）の欠落で、危険性の程度がCLASSⅠとされている点です。誰がいくら損をするかという話ではなく、小麦アレルギーの人が表示を信じて買うと症状につながりかねない、という種類の回収です。公式には健康被害の報告は無いとされていますが、対象の日に橿原店で買って食べた人で体調に不安が残る場合は、売場への連絡を後回しにしないでください。

なぜ今こうなったか。公式に確認できるのは、表示の欠落が分かり、2026年11月19日に回収へ着手し、販売店のPOPで周知しているという流れまでです。表示が欠けた原因は公式には未発表です。次に見るべきは、回収割合が11月18日時点の0％からどう動くかと、原因や再発防止が公式に追加されるかどうかです。
