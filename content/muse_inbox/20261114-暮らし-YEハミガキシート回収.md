株式会社ディプロの「YEハミガキシート」のロット「6C26」が、袋の封（トップシール）の溶着不良で自主回収されています。回収の開始は2026年11月6日で、出荷数量は10,200個です。対象のロットを持っている人は、まずロット番号と封が閉じているかを確かめ、使用を控えて、購入した店舗かディプロの窓口へ連絡してください。

## 対象はロット「6C26」だけです

回収の対象は、製品名とロットで決まります。公式の回収情報に載っている条件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 製品名 | YEハミガキシート |
| 製造販売業者 | 株式会社ディプロ |
| 対象ロット | 6C26 |
| 出荷数量 | 10,200個 |
| 出荷時期 | 2026年4月1日 |
| 回収の理由 | トップシール部の溶着不良（封が閉じていない部分がある） |
| 回収開始日 | 2026年11月6日 |
| 区分 | 化粧品の自主回収（クラスII） |

対象はロット「6C26」のみで、ほかのロットのYEハミガキシートは、この回収の対象として案内されていません。

## 自分は対象か、ロットと封の確かめ方

確かめる点は2つです。

1つ目は、製品に表示されたロット番号が「6C26」かどうかです。ロット番号の印字されている場所は、公式の回収情報には示されていません。表示が見つからない場合は、後述のディプロの窓口に問い合わせてください。

2つ目は、封の状態です。今回の不良は、袋の上部を封する部分（トップシール）の溶着が不十分で、閉じていない部分があるというものです。封が開いている、またはシートが乾燥している製品は、不良の可能性があります。ディプロの説明では、乾燥した場合は触った感触で容易に分かり、使用を避けることができる、とされています。

ロットが「6C26」で、封に異常があるものはもちろん、封に異常が見当たらなくても、対象ロットの製品は回収の対象です。使用を控えてください。

## 体への影響はどう発表されているか

ディプロは、健康への影響について次のように説明しています。

- 本品はキットに封入されているため、外部からの微生物などによる汚染の心配はない
- 乾燥した場合は触感で分かり、使用を避けることができる
- そのため、本品の使用による重篤な健康被害はないものと考えられる
- 現時点で、消費者からの健康被害の申し出はない

販売先から「トップシール部の溶着不良品が見つかった」と問い合わせがあり、返却品を検品したところ、封が閉じていない部分（未シール部）が確認されたため、自主回収が始まりました。健康被害の心配は小さいとされていますが、回収の対象になった以上、対象ロットは使わずに連絡するのが確実です。

## 今やること

対象かもしれない人は、次の順で進めてください。

1. 手元のYEハミガキシートのロット番号を見て、「6C26」かどうかを確かめる
2. 対象ロットなら使用を控え、封が開いているもの・乾燥しているものは使わない
3. 購入した店舗、またはディプロの窓口（0896-74-5588）に連絡する
4. 返品・交換・返金の具体的な手順は、公式の回収情報には明記されていないため、連絡したときに確認する

回収そのものは、ディプロが販売先へ文書で通知して進められています。店頭の在庫はその流れで回収されますが、すでに購入して手元にある分は、自分でロットを確かめて連絡する必要があります。

## よくある疑問に先に答えます

### ロット6C26以外は対象ですか

公式の回収情報で対象とされているのは、ロット「6C26」のみです。ほかのロットの製品は、この回収の対象として案内されていません。

### すでに使ってしまいました

公式の説明では、本品の使用による重篤な健康被害はないものと考えられ、現時点で健康被害の申し出もありません。体調に不安がある場合は、ディプロの窓口に相談してください。

### 返金や交換はしてもらえますか

公式の回収情報には、消費者向けの返金・交換の手順は書かれていません。購入した店舗かディプロの窓口に連絡し、対応を確認してください。

## サイソクの見方

なぜ今こうなったか：販売先で封の不良品が見つかり、返却品の検品で未シール部が確認されたことが、公式に示された経緯です。対象が1ロットに限られているのは、不良が確認されたのがこのロットの製品だったためと読めます。

誰がどうするか：出荷数量は10,200個で、健康被害の申し出は現時点でありません。影響が大きいのは、対象ロットを買ったことに気づかないまま保管している人です。回収は販売先への通知で進むため、手元にある分は自分の確認が欠かせません。
