味の素株式会社の家庭用37品種が、2026年12月1日納品分から値上げされます。
上がるのはメーカーが出荷する価格で、幅は約5～15％です。
「味の素」「アジシオ」「瀬戸のほんじお」「パルスイート」などを買っている家庭が対象です。

## 37品種の中身は、塩だけで13品種あります

公式発表に載っている対象は、次の37品種です。

| 商品群 | 品種数 |
|---|---|
| うま味調味料「味の素」 | 5品種 |
| 「うま味だし・ハイミー」 | 3品種 |
| 「アジシオ」 | 5品種 |
| 「瀬戸のほんじお」 | 5品種 |
| 「やさしお」 | 3品種 |
| 「パルスイート」 | 2品種 |
| 「パルスイート スリムアップシュガー」 | 3品種 |
| 「パルスイート おなかすこやかオリゴ」 | 1品種 |
| 「クノール たんぱく質がしっかり摂れるスープ」 | 6品種 |
| 「たんぱく質がしっかり摂れる味噌汁」 | 2品種 |
| 「アクアソリタ」ゼリー | 2品種 |
| 合計 | 37品種 |

価格の前後を、出荷価格を100とした指数で比べるとこうなります。品目ごとの改定後の円価格は、公式発表には載っていません。

|  | 改定前 | 改定後（2026年12月1日納品分から） |
|---|---|---|
| 家庭用37品種の出荷価格（指数） | 100 | 105～115 |

たとえば出荷価格が1,000円の商品なら、改定後は1,000円×1.05＝1,050円から1,000円×1.15＝1,150円の範囲になります（サイソク編集部の計算）。

これはあくまでメーカーの出荷価格です。スーパーの値札が12月1日に一斉に同じ幅で上がるわけではなく、店頭価格をいついくらにするかは店ごとに決まります。12月1日より前に納品された在庫は、改定前の出荷価格で入っています。

ここが、この記事だけのなるほどです。今回の37品種の一覧に「ほんだし」の名前はありません。「味の素の調味料は全部上がる」と思ってほんだしまで買い足す必要は、今回の発表からは出てきません。もう1つ、通販で「味の素KK プロテインスープ」「プロテインみそ汁」を買っている人は日付が別です。この2品種はEC向けとして、2026年11月1日納品分からすでに改定の扱いになっています。12月の37品種と取り違えないでください。

## 原料だけではなく、包む費用も理由に入っています

味の素は理由として、各製品の主原料をはじめとした原料価格の高騰が続いていることに加え、加工費・包材費なども継続的に上昇していることを挙げています。合理化・効率化に努めてきたものの、出荷価格を改定せざるを得ない状況になった、という説明です。

調味料は1回に使う量が少ないため、値札が数十円動いても気付きにくい商品です。だからこそ、買い替えのときに前回の購入価格と比べる習慣が効きます。

## 買い足す前に、棚の中の残量を見ましたか

判断に迷う場面ごとの目安は、次のとおりです。広告のために結論を寄せた表ではありません。

| 状況 | おすすめ | 理由 | 出どころ |
|---|---|---|---|
| 「アジシオ」「瀬戸のほんじお」が残り少ない | 普段の使用量で使い切れる分だけ買い足す | 対象は塩類だけで13品種あり、12月1日納品分から出荷価格が約5～15％上がるため | 味の素株式会社「家庭用製品出荷価格改定のお知らせ」（2026年9月1日） |
| 「ほんだし」しか使っていない | 今回の発表では買い足さなくてよい | 37品種の一覧に「ほんだし」は載っていないため | 同発表の対象製品一覧 |
| 「パルスイート」を毎日使っている | 12月以降、買う店の値札で実際の上がり幅を確かめる | 上がるのは出荷価格で、店頭価格は店ごとに決まるため | 同発表（納品分の定義と改定率） |
| ECでプロテインスープを買っている | 11月1日改定分として価格を確かめる | EC向け2品種は12月ではなく2026年11月1日納品分からの改定のため | 同発表の価格改定時期 |

- お客様向けお問い合わせ先（公式発表に記載）：うま味調味料「味の素」「うま味だし・ハイミー」「アジシオ」「瀬戸のほんじお」「やさしお」はフリーダイヤル0120-68-8181です。甘味料「パルスイート」などは0120-16-0505、健康ケア「クノール たんぱく質がしっかり摂れるスープ」「アクアソリタ」ゼリーなどは0120-814-222、EC向け「味の素KK プロテインスープ」「プロテインみそ汁」は0120-324-324です。買っている商品の群に合った番号にかけてください。

## サイソクの見方：上がる幅より、対象と対象外の線引きが大事な値上げです

今回の発表で家計が読むべきなのは、約5～15％という幅そのものより、37品種に入っているものと入っていないものの線引きです。塩類13品種と甘味料6品種が入る一方で、「ほんだし」は入っていません。

負担の置き換えも単純です。出荷価格ベースでは、改定後の価格は改定前の1.05倍から1.15倍になります（サイソク編集部の計算）。

店頭ではこの幅がそのまま出るとは限りません。12月に入ってから、いつもの店で対象品の値札を1つ確かめる。それで十分に、この値上げへの対応は終わります。慌てて棚買いをする必要はありません。
