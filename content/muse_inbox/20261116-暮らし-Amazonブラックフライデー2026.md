Amazonブラックフライデー2026は、開催すること自体は公式に発表されています。ただし、2026年11月16日時点で公式に示されているのは、開催期間やセール情報などの詳細を11月19日（木）午前に公開する予定までです。開始日、終了日、先行セールの有無はまだ発表されていません。

11月19日は、詳細を公開する予定の日です。公式発表は19日をセール開始日とはしていないため、カレンダーには「19日午前に日程を確認」と入れるのが正確です。11月16日から11月19日までは3日あります（19日 − 16日 = 3日）（サイソク編集部の計算）。

## 決まっていることは、開催と19日午前の詳細発表

Amazonの公式発表では、2026年のAmazon ブラックフライデーで、食品や日用品、家電、人気ブランドのアイテムなどを取りそろえ、特別価格で提供するとしています。大切な人へのギフトや、1年間がんばった自分へのご褒美も用途として挙げられています。

現時点で決まっている範囲は、次の表のとおりです。

| 項目 | 公式に決まっていること |
|---|---|
| イベント | 2026年の「Amazon ブラックフライデー」を開催する |
| 詳細の公開 | 2026年11月19日（木）午前中 |
| 商品分野の例 | 食品、日用品、家電、人気ブランドのアイテム |
| 今年の買い物キーワード | 「ピタリ買い」 |
| 公式の準備案内 | 予算を分ける、ほしい物リストに集める、受け取る日と場所を決める |

「ピタリ買い」は、予算、自分の欲しい物や用途、タイミングの3つが合う買い物を指します。Amazonは11月12日の公式記事で、セール前にこの3つを準備する方法を紹介しています。

## まだ出ていないこと：日程も、割引率も、ポイント条件も未発表

2026年11月16日時点で、公式発表と準備案内を確認した範囲では、次の内容はまだ出ていません。

| 項目 | 11月16日時点の状態 |
|---|---|
| 本セールの開始日・終了日と時刻 | 未発表 |
| 先行セールの有無と日程 | 未発表 |
| 対象商品の名前、ブランド、価格 | 未発表 |
| 割引率、クーポンの有無と条件 | 未発表 |
| ポイントアップキャンペーンの有無 | 未発表 |
| ポイント率、上限、対象金額、エントリー期間 | 未発表 |
| プライム会員限定のセールやキャンペーン | 未発表 |
| スタンプラリーなどの追加企画 | 未発表 |
| Amazonネットスーパーなど分野別の企画 | 未発表 |

特に注意したいのは、ポイント条件です。昨年はポイントアップキャンペーンがありましたが、それは2025年の条件です。今年も同じキャンペーンがあるか、エントリーが必要か、プライム会員で何ポイント増えるかは、11月19日の詳細発表を待つ必要があります。

また、公式の準備案内には、プライム会員が対象商品のお急ぎ便やお届け日時指定便を追加料金なしで利用できると書かれています。これは配送特典の案内です。今年のブラックフライデーにプライム会員限定価格や会員限定キャンペーンがあるとは、まだ発表されていません。

## 昨年は11月24日から12月1日まで、今年の日程とは分けて読む

昨年、2025年のAmazon ブラックフライデーは、11月24日（月）0時から12月1日（月）23時59分まで開催されました。先行セールは11月21日（金）0時から11月23日（日）23時59分まででした。

昨年はポイントアップキャンペーンやスタンプラリーもありましたが、これらは昨年の実施内容です。今年の開始日を昨年の11月24日と予想したり、昨年のポイント率を今年の条件として使ったりはできません。今年の期間と条件は、11月19日午前の公式発表で初めて分かります。

## 今やることは、買う物を分けて19日午前に条件を見ること

公式の準備案内に沿うと、詳細が出る前にできることは3つです。

### 1. 用途ごとに予算を分ける

日用品のまとめ買い、自分へのご褒美、ギフトなど、用途ごとに大まかな予算を分けておきます。対象商品や割引率が未発表の段階では、商品名ではなく「何に、いくらまで使うか」を先に決める形です。

### 2. 気になる商品をほしい物リストに入れる

候補の商品をほしい物リストへ集めておくと、セール開始後に価格を確認しやすくなります。ギフト用は、家族やパートナーとリストを共有する方法も公式案内にあります。11月19日に日程と対象商品が分かったら、リスト内の商品がセール対象か、価格がどう変わったかを1つずつ確かめます。

### 3. 受け取りたい日と場所を決める

ギフトを渡す日や商品を使い始める日を先に決めておきます。公式案内では、お届け日時指定便のほか、コンビニなどのAmazon受取スポットやAmazonロッカーで受け取る方法も紹介されています。家族に知られずギフトを受け取りたい場合にも、自宅外受け取りを選べます。

プライム配送を使う予定がある人は、Amazonカスタマーサービスの「配送・プライム」から、プライム会員情報と特典の状態を確かめておけます。ただし、会員であることと、今年のブラックフライデーで会員限定の割引を受けられることは別です。会員限定企画の有無は19日の発表で確認してください。

エントリーについても、11月16日時点では今年のブラックフライデー向けポイントアップキャンペーンと、そのエントリー方法は公式に出ていません。今の段階で「エントリーした」と扱わず、19日午前の発表後に公式のキャンペーン案内で期間と方法を確認するのが安全です。

## 公式の窓口は、About Amazon Japanの発表とカスタマーサービス

最新の日程とセール情報は、About Amazon Japanの公式発表「Amazon、2026年『Amazon ブラックフライデー』を開催」（https://www.aboutamazon.jp/news/retail/amazon-black-friday-2026）で確認します。たどり方は、About Amazon Japanの「ニュース」から「リテール」を選び、この記事を開く方法です。開催期間やセール情報などの詳細は、11月19日午前に公開予定とされています。

準備の詳細は、About Amazon Japan「Amazonブラックフライデーをもっと楽しむための3ステップ」（https://www.aboutamazon.jp/news/retail/3-steps-for-amazon-black-friday-2026）に出ています。予算の分け方、ほしい物リスト、自宅外受け取りの案内がまとまっています。

プライム会員情報や特典を確認する場合は、Amazonカスタマーサービス「配送・プライム」（https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GGE5X8EV7VNVTK6R）を使います。ページ内の「プライム会員情報の管理」や「特典の確認・キャンセル」へ進む案内があります。

## サイソクの見方：今年いちばんの境目は「19日は開始日ではない」こと

今回の情報で混同しやすいのは、11月19日という日付です。19日は詳細の公開予定日で、セールの開始日ではありません。昨年の日程やポイント条件を今年へ当てはめると、買う日も予算もずれてしまいます。

11月19日午前に見る順番は、開催期間、対象商品、割引やポイントの条件、エントリーの要否の4つです。ほしい物リストと予算を先に用意しておけば、発表後はこの4点を確かめるだけで済みます。

次に読む記事として、楽天ブラックフライデー2026のエントリーとポイント上限をまとめた記事もあわせて確認できます。
