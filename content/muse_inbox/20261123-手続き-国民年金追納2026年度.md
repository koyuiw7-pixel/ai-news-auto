学生の頃や収入が少なかった頃に、国民年金保険料の免除や学生納付特例を受けたままになっていませんか。その期間は、後から保険料を納める「追納」で老齢基礎年金の額を満額に近づけられます。ただし追納できるのは、追納が承認された月の前10年以内の期間だけです。10年を過ぎた月は、後から納めたくても納められません（日本年金機構「国民年金保険料の追納制度」、2026年4月1日更新）。

## 令和8年度の追納額は、対象の年度で月額が違います

令和8年度（2026年度）中に追納する際の保険料額は、免除などを受けた年度と免除の区分で決まります。全額免除・納付猶予・学生納付特例だった月の月額は、次のとおりです。

| 対象の月分 | 追納月額 |
|---|---|
| 平成28年度分 | 16,850円 |
| 平成29年度分 | 17,070円 |
| 平成30年度分 | 16,900円 |
| 令和元年度分 | 16,950円 |
| 令和2年度分 | 17,070円 |
| 令和3年度分 | 17,110円 |
| 令和4年度分 | 16,990円 |
| 令和5年度分 | 16,770円 |
| 令和6年度分 | 16,980円 |
| 令和7年度分 | 17,510円 |

まとめて納める場合の目安は、令和7年度分なら17,510円×12か月＝210,120円（サイソク編集部の計算）、令和5年度分なら16,770円×12か月＝201,240円（サイソク編集部の計算）です。

免除・納付猶予の承認を受けた期間の翌年度から起算して3年度目以降に追納する場合は、当時の保険料額に経過期間に応じた加算額が上乗せされます。令和6年度分と令和7年度分には、追納加算額はありません。先送りするほど加算が付く年度が増えるため、古い月ほど「まだ間に合うか」と「いくら増えているか」を一緒に確かめる必要があります。

## 1年分を納めると、年金は年約1万円か約2万円増えます

日本年金機構によると、1年間分を追納すると、全額免除の期間であれば老後の年金が年間で約1万円、納付猶予や学生納付特例の期間であれば年間で約2万円増えます。納付猶予や学生納付特例の期間は年金の受給資格期間には計算されますが、追納しないと年金額には反映されません。

なるほど: 追納した保険料は、社会保険料控除の対象にもなります。追納そのものは年金額を増やす手続きですが、納めた年の控除にも関わるため、年末が近い時期は「どの月に納付書で払うか」まで含めて年金事務所に確認すると、申込書を出したのに納付が期限直前になる事態を避けられます。日本年金機構も、追納申込書を追納期限の直前に提出すると期限までに追納できなくなる場合があるとして、早めの提出を呼びかけています。

## 自分は対象か、最初に確かめる3つの条件

1. 免除、納付猶予、学生納付特例のいずれかの承認を受けた期間があること。
2. その期間が、追納が承認された月の前10年以内にあること。
3. 老齢基礎年金を受け取ることができる状態ではないこと。日本年金機構は、老齢基礎年金を受け取ることができる方は追納できないとしています。

一部免除を受けた期間には注意が必要です。納付すべき一部保険料が納付されていなければ、その期間は追納できません。また、保険料は原則として古い期間から納付しますが、免除の期間と納付猶予・学生納付特例の期間の両方がある人は、納付する順序について年金事務所に相談するよう案内されています。

## 申し込みは年金事務所だけです　街角の年金相談センターではできません

公式窓口: 日本年金機構（nenkin.go.jp）の「国民年金保険料の追納制度」。たどり方: 日本年金機構トップページ → 手続き・届出 → 国民年金 → 免除・猶予 → 「国民年金保険料の追納制度」。提出先はお近くの年金事務所で、窓口のほか郵送でも手続きできます。街角の年金相談センターでは手続きできません。

申込書は「国民年金保険料 追納申込書」です。「ねんきんネット」の画面上で申込書を作成することもできますが、これは電子申請ではありません。入力して印刷した届書を、年金事務所へ提出する必要があります。提出後、日本年金機構から納付書が届くので、その納付書で金融機関、郵便局、コンビニエンスストア、電子納付（Pay-easy）、スマートフォンアプリのいずれかで納めます。口座振替、クレジットカード、ねんきんネットを活用した「納付書によらない納付」では納められません。

窓口でマイナンバーにより申請する場合はマイナンバーカードを提示します。持っていない場合は、マイナンバーが確認できる書類と、運転免許証やパスポートなどの身元確認書類の両方が要ります。郵送の場合は、マイナンバーカードの表・裏両面のコピー、またはその2種類のコピーを添付します。

## サイソクの見方：期限が近い月から並べると、判断を間違えにくくなります

追納は「まとめて全部納めるか、何もしないか」の二択で考えると金額が大きく見えますが、制度上は全部または一部の納付ができます。まず10年の期限が近い月から並べ、次に加算額が付き始める年度を確認し、最後に1年分の目安額で無理のない月数を決める順番が現実的です。年金額の増え方は全額免除で年約1万円、納付猶予・学生納付特例で年約2万円と期間の種類で違うため、自分の期間がどちらだったかを曖昧にしたまま金額だけ比べないことも大切です。
